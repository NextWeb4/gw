# HxHwang Gw 帮助

HxHwang Gw 公开演示版将任务、文件索引、文稿和迁移结果保存在当前浏览器的 IndexedDB 中，不连接私有 API 或 AI。桌面版使用同一套本地数据模型，并通过受限 Electron 接口导出 PDF。

内网 Web 与桌面版可在“关于与设置”中显式填写私有 API 地址和一次性访问码。访问码只保留在当前页面内存中；同步先拉取服务端主版本，再按 `updatedAt` 推送本地较新版本，冲突时保留服务端返回的主版本。任务、文件、草稿和引用附件参与同步，历史档案继续只读保留。

## 数据边界

- 仅录入公开或内部非涉密材料；涉密材料不得进入本系统或公网模型。
- 导入前保留原系统导出文件，导入完成后查看迁移报告和历史档案数量。
- 更换浏览器、清理站点数据或卸载前，先在“数据迁移”中导出本地快照。
- 公网 AI 仅能经私有网关处理已脱敏、逐次确认的内容；公开演示版不提供此能力。
- 本地脱敏会替换常见手机号、邮箱、身份证号和带标签姓名，但不能证明材料已完全匿名；发送前必须人工检查并可继续修改脱敏预览。
- 服务端模型密钥和数据库凭据不得写入客户端；桌面访问码不会写入 IndexedDB。

## 导出

- DOCX 使用 A4 页面和中文公文字体名称；目标机器缺少字体时会回退，正式发文前必须在 Word 中复核。
- Web 端 PDF 通过浏览器打印预览保存；桌面端通过 Electron A4 打印接口保存。
