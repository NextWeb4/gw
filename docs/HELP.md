## 1. 使用前必须了解的边界

### 1.1 数据保存在什么地方

- 任务、会议、文件、外出活动、用章、物资、主草稿、周报、历史档案、常用人员和单位、自定义格式及附件首先保存在当前浏览器配置或当前桌面客户端用户数据目录的 IndexedDB 中。
- “本机保存”不等于“整台电脑所有用户共享”。不同浏览器、无痕窗口、不同 Windows/Linux 用户和不同浏览器配置的数据彼此独立。
- 只有内网版在用户建立会话并点击“同步全部业务数据”后，才会把支持同步的记录与私有服务端交换。系统没有后台自动同步。
- 公开 Pages 与互联网版只有在用户点击“获取 AI 模型”或确认发送后才请求所选模型服务；公开 Pages 不连接私有 API，内网版也不会直连公网模型。

### 1.2 哪些材料可以录入

- 当前版本定位为公开演示或内部非涉密工作辅助工具，不具备涉密系统资质。
- 涉密材料、个人敏感信息、未经授权的内部文件不得录入公开 Pages，也不得发送到公网模型。
- 本地 IndexedDB 和快照没有额外的应用层加密。设备磁盘加密、系统账号权限、浏览器配置保护和备份介质管理仍由使用单位负责。
- AI 输出、自动小结和周报汇总都不能替代人工审签、政策审核、事实核验、保密审核和正式排版复核。

| --- | --- | --- | --- | --- |

## 2. 版本与能力选择

### 2.1 能力对照表

| 能力 | 公开 Pages | 互联网 Web | 互联网桌面版 | 内网 Web | 内网桌面版 |
| --- | --- | --- | --- | --- | --- |
| 六类业务台账、事务日历、写作、周报 | 支持，本机保存 | 支持 | 支持 | 支持 | 支持 |
| 本机 IndexedDB | 支持 | 支持 | 支持 | 支持 | 支持 |
| 本机附件（单个不超过 8 MB） | 支持 | 支持 | 支持 | 支持 | 支持 |
| 历史 JSON / 快照恢复 | 支持，本机解析 | 支持 | 支持 | 支持 | 支持 |
| 导出本地快照 | 支持 | 支持 | 支持 | 支持 | 支持 |
| 用户自备 Key 的 OpenAI 兼容 AI | 支持，受 CORS 限制 | 支持，受 CORS 限制 | 支持 | 不提供 | 不提供 |
| 私有同步 | 不提供 | 不提供 | 不提供 | 手动触发 | 手动触发 |
| 内部 AI 网关 | 不提供 | 不提供 | 不提供 | 支持 | 支持 |
| PDF 导出 | 浏览器打印 | 浏览器打印 | 原生保存对话框 | 浏览器打印 | 原生保存对话框 |
| 首次访问后离线重开 | 支持已缓存的同源资源 | 取决于部署与缓存 | 应用本体离线可开 | 取决于部署与缓存 | 应用本体离线可开 |

“互联网版”和“内网版”是能力边界，不是数据密级认证：

- 公开 Pages 和互联网版适合可访问公网模型接口的非涉密或公开材料，不提供私有同步。
- 内网版只连接用户填写的内部 HxHwang Gw API，不允许通过界面直连公网 AI。
- 公开 Pages 是公开静态站点。业务记录、附件和导入内容只保存在当前浏览器，但没有应用层加密、组织权限或审计能力，不得把它当作涉密或正式生产系统。

### 2.2 如何确认当前版本

1. 查看左侧导航上方或移动端底部显示的“公开演示版”“互联网版”或“内网版”。
2. 进入“关于与设置”。
3. 核对版本号、构建时间、运行模式和数据位置。
4. 桌面客户端会显示“桌面互联网版”或“桌面内网版”。

如果界面类型与下载文件名中的 `internet` / `intranet` 不一致，应停止录入并重新下载安装正确版本。

## 3. 下载、安装、升级和卸载

### 3.1 选择正确的安装包

从 [GitHub Releases](https://github.com/NextWeb4/gw/releases/latest) 下载。文件名同时包含版本、分版和架构。

也可进入“关于与设置”，点击“下载安装包”跳到“下载桌面客户端”，切换互联网版/内网版并选择对应系统架构。系统不会猜测 CPU 架构，也不会自动开始下载；请先人工确认。

| 系统 | 架构 | 互联网版示例后缀 | 内网版示例后缀 |
| --- | --- | --- | --- |
| Windows 10/11 | x64 | `internet-x64-setup.exe` | `intranet-x64-setup.exe` |
| Windows 10/11 | ARM64 | `internet-arm64-setup.exe` | `intranet-arm64-setup.exe` |
| Debian/Ubuntu | amd64 | `internet-amd64.deb` / `internet-x86_64.AppImage` | `intranet-amd64.deb` / `intranet-x86_64.AppImage` |
| Debian/Ubuntu | arm64 | `internet-arm64.deb` / `internet-arm64.AppImage` | `intranet-arm64.deb` / `intranet-arm64.AppImage` |

- Windows：进入“设置 > 系统 > 系统信息 > 系统类型”查看架构。
- Debian：执行 `dpkg --print-architecture`，输出应为 `amd64` 或 `arm64`。
- Debian 10 仅作为兼容目标，日常运行优先 Debian 12。
- 互联网版、内网版和对应 Electron 安装包首次启动为空业务库，不初始化公开 Pages 的虚构演示记录；如需旧数据，请从“数据迁移”导入或恢复快照。

### 3.2 校验下载文件

Release 同时提供 `SHA256SUMS.txt`。

Windows PowerShell：

```powershell
Get-FileHash .\HxHwang-Gw-安装包文件名.exe -Algorithm SHA256
```

Debian/Linux：

```bash
sha256sum HxHwang-Gw-安装包文件名.deb
```

把结果与 `SHA256SUMS.txt` 中同名文件的哈希逐字对照。不一致时不要运行安装包，应重新下载并核对来源。

### 3.3 Windows 安装

1. 关闭正在运行的旧版客户端。
2. 双击正确的 `setup.exe`。
3. 按向导选择当前用户安装位置并完成安装。
4. 当前安装包未进行 Authenticode 代码签名，Windows 可能显示“未知发布者”。只应使用本项目 Release 中、已核对 SHA-256 的文件。
5. 启动后进入“关于与设置”，核对版本和分版。

### 3.4 Debian 安装

推荐使用 APT 安装 `.deb`，让系统同时处理依赖：

```bash
sudo apt install ./HxHwang-Gw-安装包文件名.deb
```

不要使用忽略依赖的强制安装参数。安装完成后从应用菜单启动，并到“关于与设置”核对版本。

AppImage 免安装使用：

```bash
chmod +x HxHwang-Gw-文件名.AppImage
./HxHwang-Gw-文件名.AppImage
```

### 3.5 升级

1. 在旧版“数据迁移”中点击“导出快照”。
2. 确认 JSON 文件能正常打开，且包含 `format: hxhwang-gw-local-v1` 和 `records` 数组。
3. 完全退出旧版客户端。
4. 安装新版本，不要同时运行两个版本编辑同一份本机数据。
5. 启动新版本并核对版本号、六类业务台账、草稿和周报。
6. 只有本机数据确实缺失时才恢复快照；恢复属于合并/更新，不是“回到某一时刻”的整体替换。

### 3.6 卸载

- Windows：从“设置 > 应用 > 已安装的应用”卸载对应分版。
- Debian 互联网版：`sudo apt remove hxhwang-gw-internet`。
- Debian 内网版：`sudo apt remove hxhwang-gw-intranet`。
- AppImage：退出应用后删除 AppImage 文件。

不要依赖卸载程序保留或删除本机业务数据。卸载、清理浏览器配置或删除用户目录前，必须先导出并验证快照。

## 4. 五分钟快速开始

1. 打开应用，确认当前是公开演示版、互联网版还是内网版。
2. 按 `Ctrl/Cmd+K` 打开全局命令面板，输入“新建任务”“登记文件”或其他业务命令，可直接打开六类原编辑抽屉；需要从通知文字提取任务时，点击顶栏“快速记录”或按 `Shift+A`。两种入口都不会自动保存，填写完成后仍须点击原保存按钮。
3. 按实际工作进入“会议管理”“文件收发”“外出活动”“用章管理”或“物资收发”，各保存一条需要跟踪的台账记录。已有相近记录时，可先打开右侧详情并点击“复制相似记录”，在原编辑抽屉核对后再保存。
4. 进入“事务日历”，选择当天或已有事项的日期，确认六类台账是否按日期汇总；点击议程可回到原台账详情。
5. 进入“公文写作”，选择一个模板，修改标题和正文，点击“保存版本”。
6. 进入“周报生成”，选择日期范围，点击“重新汇总”，核对六类台账素材和正文后保存并导出。
7. 如需 AI，先在“AI 助手”配置自备 Key 或内网会话；公文写作和周报生成页的“AI 润色”会在当前页面打开协作面板，完成脱敏、逐次确认并显示结果，不切换导航模块。
8. 进入“数据迁移”，点击“导出快照”，把文件复制到受控备份位置。

公开 Pages 具备完整本机台账、附件、迁移和自备 Key AI 功能，但仍是公开静态站点，不具备组织权限、应用层加密或涉密资质。只应使用公开、虚构或经过批准的非敏感材料。

## 5. 界面、保存和删除的通用规则

### 5.1 导航与提示

- 桌面宽屏从左侧导航进入模块；点击导航顶部的收起按钮后，左栏缩为图标模式，鼠标悬停可查看模块名称，再次点击展开。手机或窄屏继续使用底部导航，模块名称和数据相同。
- 任务、会议、文件、外出、用章和物资在宽屏下采用三栏结构：左侧导航、中间列表、右侧只读详情。点击列表记录会切换右侧详情；“编辑此记录”与列表铅笔按钮都会打开同一个编辑抽屉。
- 六类只读详情标题下方显示“当前可见 A / B”以及上一条、下一条图标按钮。顺序严格跟随当前模块已经筛选和排序后的列表，第一条禁用上一条，最后一条禁用下一条，不循环；按钮提示会包含目标记录标题，可用 Tab 聚焦并用 Enter 或 Space 操作。
- 上一条/下一条只切换既有选中记录，不清除当前关键词、筛选和排序，也不改写业务字段。切换继续使用原最近访问和窄屏详情定位路径，不写入 IndexedDB、localStorage、快照或同步服务，也不发起网络请求。
- 六类详情还提供独立的“跨模块轨迹”后退/前进按钮。任务—文件关联、周报来源、事务日历、工作台、星标、全局查找和台账行等显式记录入口都会进入同一条访问历史；按钮名称会说明目标模块和记录标题。它与“当前可见上一条/下一条”不同：前者返回跨模块来源，后者只浏览当前筛选结果。
- 跨模块历史最多 20 条，只保存当前 React 会话中的模块和记录 ID。连续点击当前同一记录不会重复，也不会破坏已有前进分支；后退后打开不同记录会截断前进分支；软删除或永久删除会裁剪目标，恢复不会自动加入；刷新、关闭页面或重启客户端会清空。历史导航仍复用 `openBusinessRecord`，会清除可能隐藏目标的会话筛选并打开原只读详情。
- 右侧详情的“复制相似记录”会把当前 active 记录转换成一个新 ID 的未保存草稿，并继续打开同一个编辑抽屉。复制不会立即写入本机；抽屉会明确显示复制说明和“未保存修改”。
- 右侧详情的“对比记录”会打开独立的原生只读对话框：当前记录固定为左侧基准，右侧候选只来自同模块仍为 active 的已加载记录，默认优先当前筛选结果的下一条、上一条，再回退到第一条其他记录。候选列表保持数组顺序，可用“搜索同类记录”本地筛选，不会发起请求或重排上游数据。
- 对比对话框支持“全部字段 / 仅看差异”切换，并显示差异数量。字段按六类台账的固定白名单逐行对齐，包含标题、状态/类型、业务日期、人员/单位、摘要、备注、关系标题和附件数量；空值显示“未填写”，关系只显示当前 active 记录标题。不会显示内部 ID、删除/墓碑字段、迁移原文、来源版本、附件正文/Base64/哈希、API Key、访问码或 AI 原文。
- 对比只存在当前 React 会话，不写入 IndexedDB、快照、私有同步、访问轨迹或星标；不改变台账关键词、筛选、排序、当前选中记录或编辑器。模块切换、对比记录失效或刷新数据后对象不可用时，对话框会关闭并提示，恢复记录不会自动重开。Escape、关闭按钮和外侧点击均关闭并恢复触发按钮焦点。
- 六类 active 记录的右侧详情还提供“复制记录摘要”。摘要使用与只读对比一致的固定字段白名单和显示顺序，首行注明模块与记录标题，随后输出状态/类型、业务日期、人员/单位、摘要、备注、当前 active 关系标题、附件数量和最近更新时间；多行字段以缩进续行，便于粘贴到聊天、邮件或文稿中核对。
- 摘要不会包含记录 ID、删除/墓碑字段、迁移原文、来源版本、附件 ID/正文/Base64/哈希、API Key、访问码、中转密码或 AI 原文。点击后只向当前设备的系统剪贴板写入纯文本，不改业务记录、筛选、排序、访问轨迹、星标、IndexedDB、快照或同步，也不发起网络请求；系统剪贴板确认成功后才提示“已复制”，权限拒绝或 API 不可用会明确提示失败。复制本身不会自动发送、保存或粘贴内容。
- 六类右侧详情右上角共用一个星标按钮；按下状态表示当前记录已加入本机星标。星标只改写独立本机设置，不修改业务记录、更新时间、附件、筛选、排序或同步 payload，也不会形成第二套业务保存逻辑。
- 右侧详情不会自动保存或改写记录；在窄屏下详情会回到中心内容流。点击列表记录后页面会自动定位到对应详情，详情中的“返回记录列表”会回到列表区域，编辑、保存、删除规则不变。
- 切换导航模块后，页面会回到新模块顶部。六类业务抽屉出现“未保存修改”时，点击取消、关闭按钮、外侧区域或按 Escape 都会先询问是否放弃；没有修改的抽屉直接关闭。
- 顶栏“全局查找”或 `Ctrl/Cmd+K` 会打开本机命令面板。空查询时先显示当前 active 的“星标记录”，再显示最多六条当前会话“最近访问”；同一记录已经星标时不会在最近访问中重复出现。之后是“快速新建”、十七个导航模块，以及按任务、会议、文件、外出、用章和物资分组的当前 active 记录。输入模块名称、记录标题、当前台账支持的搜索字段，或“新建”“创建”“登记”等动作词后，星标和最近访问两个快捷组都隐藏；可用上下键选择、Enter 打开、Escape 关闭，普通关闭后焦点回到打开前的控件。回收站记录和永久删除墓碑不会混入业务结果。
- “快速新建”提供新建任务、新建会议、登记文件、新建外出活动、新建用章记录和新建物资记录。选择命令后，面板先关闭，再进入对应原业务模块并打开原编辑抽屉，焦点落到第一个可编辑字段；命令不会直接调用保存、创建简化表单或建立第二套附件会话。
- 选择全局查找中的业务记录，只会进入原业务模块并选中原记录：宽屏继续显示既有右侧只读详情，窄屏继续使用既有详情定位和“返回记录列表”。为保证命中的记录可见，系统会清除目标台账当前会话的关键词、筛选和排序；该入口不会新建记录、自动保存、修改当前记录或形成第二套详情页。
- “最近访问”只在用户通过台账行、日历、工作台或查找结果显式打开六类 active 记录时更新；自动显示的首条详情不计入。列表按最近访问排序、重复访问移到首位，并只保存模块与 ID，不保存标题、正文、附件或时间。软删除后引用立即移除，恢复不会自动重新加入；再次显式打开后才会重入。页面刷新、关闭或重新加载后列表清空。
- 星标最多 12 条，按最近加入顺序显示；达到上限时会明确提示，不会静默挤掉旧星标。设置只保存 `kind`、记录 ID 和星标时间，标题、状态与摘要由当前 active 数组实时派生，不保存业务正文、备注、附件、迁移原文或 AI 内容。软删除后星标暂时隐藏但引用保留，恢复后重新出现；永久删除或收到远端 purge 后引用会被清理。
- 全局命令面板不联网、不查询第二份数据库、不保存搜索词、命令状态或最近访问，也不索引 API Key、访问码、中转密码、relay session、未脱敏 AI 原文、备注或附件正文。“最近访问”和“跨模块轨迹”都不进入 IndexedDB、localStorage、sessionStorage、快照、日志或私有同步；星标设置进入 IndexedDB 和本地快照，但不进入私有同步。快速新建只在 React 会话中生成空草稿，取消后不会写入 IndexedDB、快照或同步；业务编辑抽屉、快速记录或当前页 AI 面板打开时入口会禁用，避免两个模态界面叠加。
- 顶栏“快速记录”或 `Shift+A` 会打开“快速记录任务”。在工作台点击“快速记录任务”进入同一流程；快捷键不会拦截输入框、文本域、下拉框或可编辑区域中的正常输入。
- 快速记录只把当前文字交给本机确定性规则并即时预览任务名称、交办人、交办日期、截止日期和任务来源。点击“继续核对”后进入原有“新建任务”抽屉；识别不到字段的非空文字也可继续手工填写，原文字会留在抽屉的智能识别区域供核对。
- 快速记录不会联网、不会写入 IndexedDB、localStorage、快照、日志或同步服务，也不会自动保存任务。取消时文字直接丢弃；继续后，抽屉从打开起即标记为未保存，最终仍须点击“保存任务”。全局查找、业务抽屉或当前页 AI 面板打开时，快速记录入口会禁用，避免模态层叠加。
- 顶部“刷新本地数据”只重新读取 IndexedDB，不保存当前抽屉中的修改，也不连接服务器。
- 操作结果以短暂提示显示。失败提示消失后，错误本身并不会自动修复。
- 列表右侧的铅笔图标用于编辑，叉号用于删除；鼠标悬停可查看按钮说明。
- 六类业务台账共用同一套“关键词 / 筛选 / 排序 / 显示数 / 清除”控制条，但每个模块拥有独立的会话状态。切换到其他模块再返回时，当前浏览器会话会恢复原关键词、筛选和排序；刷新页面或重新打开应用后不保留。
- 任务可按状态或动态类目筛选；会议可按是否已安排会议时间筛选；文件可按收发类型或登记状态筛选；外出可按活动类型筛选；用章可按文件类型筛选；物资可按入库/领用筛选。各模块还提供日期、最近更新或名称排序，空日期始终放在有日期记录之后。
- “显示 A / B”中的 A 是当前可见记录数，B 是该模块全部记录数。“清除”会恢复完整集合和原始顺序。筛选和排序只转换当前已加载数组，不改写业务记录，也不进入 IndexedDB、localStorage、快照或同步服务。
- 六类控制条中的“导出”会下载当前模块在当前关键词、结构化筛选和排序之后仍可见的 active 记录，行顺序与屏幕列表一致；当前结果为 0 时按钮禁用，不生成只有表头的空文件。文件名形如 `hxhwang-gw-任务管理-当前结果-2026-08-01.csv`。
- CSV 使用 UTF-8 BOM、CRLF 和固定中文列头，每个单元格始终加双引号。字段由六套业务白名单明确指定，不会输出记录 ID、删除/墓碑字段、迁移原文、来源版本、附件 ID/正文/Base64/哈希、API Key、访问码、中转密码或 AI 原文；附件只输出数量。任务的“关联文件”和文件的“关联任务”只输出当前 active 记录标题，不输出内部关系 ID。
- 为避免电子表格把用户文字当作公式，以 `= + - @`、对应全角字符、Tab、回车或换行开头，以及在前导空白/控制字符后出现这些前缀的单元格，会在导出时增加文本前缀。该处理只改变下载报表，不改写台账中的原始字段。
- CSV 是一次性可见结果报表，不是本地快照、迁移文件或同步格式。导出只消费页面已经加载的数组，使用本机 Blob 下载，不读取第二份数据库、不写入 IndexedDB、不保存筛选状态，也不联网。物资导出的“账面库存”仍由全部 active 物资流水计算，不会改用筛选后的当前结果。
- 物资台账即使只筛选“入库”或“领用”，每条记录显示的账面库存仍按全部物资收发记录计算，不能把当前可见集合当成库存口径。

| 全局命令面板快速新建草稿 | 否，只打开对应原业务抽屉 | 核对字段后点击该业务原保存按钮；取消则不创建记录 |
| 快速记录任务文字 | 否，只保留在当前快速记录/任务抽屉会话 | 点击“继续核对”后仍须在原任务抽屉点击“保存任务”；取消则丢弃 |
| 复制相似记录草稿 | 否，只保留在当前业务抽屉会话 | 核对复制说明和字段后点击该业务原保存按钮；取消则不创建记录 |

### 5.3 复制相似记录规则

- 复制入口只出现在六类 active 业务的右侧详情；回收站、永久删除墓碑、周报、草稿和历史档案原件不使用该入口。历史档案已有的“复制为新记录”也会进入同一未保存保护，但仍保留其历史来源说明。
- 所有复制都会生成新的记录 ID、创建时间和更新时间，不会覆盖原记录。复制草稿的嵌套单位、阶段和附件 ID 数组均为独立数组，修改草稿不会修改原对象。
- 任务会保留名称、类目、来源、交办人、交办日期、截止日期、阶段名称、备注和主附件引用；任务状态重置为“未启动”，配合单位及阶段内单位状态重置为“待反馈”，阶段生成新 ID，单位进度附件和工作小结清空。
- 文件会保留标题、文号、成文日期、来源、承办信息、分类、备注和主附件引用，但登记状态重置为“待登记”，原关联任务清空，避免新文件误继承旧业务关系。外出活动保留安排、摘要、备注和主附件引用，但旧成果记录清空。会议、用章和物资保留当前业务字段供人工调整。
- 主附件不会复制第二份二进制，只复用同一个不可变本机附件 ID。复制草稿中“解除关联”只移除新草稿的引用，不影响原记录；如果保存新记录，附件清理仍按所有 active/trash 记录和历史档案的引用共同判断。
- 复制不会自动改日期、文号、名称或数量。抽屉提示会列出需要核对的字段；必须通过原必填、四位年份日期、日期时间和正整数校验后才能保存。
- 复制抽屉从打开时就属于未保存状态。取消、关闭、外侧点击、Escape 和浏览器离开都使用统一守卫；确认放弃后不会创建记录。保存成功后系统会清除可能隐藏新记录的当前台账筛选，并在原详情栏选中新记录。
- 打开、修改、取消和保存复制草稿不会新增网络请求。只有用户之后主动执行既有私有同步时，已保存的新记录才会进入同步工作区。

### 5.4 删除、恢复和永久删除规则

- 任务、会议、文件、外出、用章和物资点击删除后先请求确认，确认后移入“回收站”。记录正文、业务字段和附件引用仍留在本机，但不会继续出现在台账、工作台、日历、统计、周报、AI 材料、常用项目录派生或全局业务搜索中。
- 回收站可按标题/摘要/附件名搜索并按六种类型筛选。恢复前会再次确认；恢复后记录回到原模块，原字段和附件保持可用，并以新的更新时间参加后续显式同步。
- “永久删除”和“清空回收站”无法撤销。永久删除会移除标题、备注、业务字段和附件 ID，只保留 `id`、`updatedAt`、`deletedAt`、`purgedAt` 四个同步墓碑字段，用于阻止其他设备上的旧记录在下次手动同步时复活。
- 软删除不会清理附件。只有永久删除后，系统才清理已经不被其他 active/trash 业务记录或历史档案引用的附件；共享附件会保留。恢复前可以直接从回收站下载仍有本机正文的附件。
- 本地快照包含 active、回收站记录和最小墓碑；已经永久删除的业务正文不会写入快照。周报仍使用原有独立删除规则，不进入六类业务回收站。
- 永久删除或清空回收站前仍建议导出快照并核对范围；但永久删除后的快照不能恢复已移除的业务正文。

### 5.5 日期规则

- 日期格式为 `YYYY-MM-DD`，年份必须恰好四位。
- 有效范围为 `1900-01-01` 至 `9999-12-31`。
- `2026-02-30`、六位年份、空的必填日期和无效日历日期都会被拒绝。
- 任务截止日期可以为空；任务交办日期、文件成文日期和周报起止日期不能为空。会议通知/会议时间、外出日期、用章日期和物资经手日期可以为空，但一旦填写就必须是真实四位年份日期。
- 系统不会根据截止日期自动把任务状态改成“已超期”，任务状态仍需人工维护。

## 6. 工作台与事务日历

工作台用于总览和进入既有业务流程；“快速记录任务”只打开会话级捕获与原任务抽屉，不在工作台直接保存记录。

### 6.1 指标含义

| 指标 | 计算方式 |
| --- | --- |
| 进行中任务 | 所有状态不是“已完成”的任务数量 |
| 近七日到期 | 截止日期不晚于未来第 7 天、且状态不是“已完成”的任务；已逾期未完成任务也包含在内 |
| 登记文件 | 当前本机文件记录总数 |
| 综合台账 | 会议、外出活动、用章和物资记录数量之和；备注同时显示历史档案数量 |

### 6.2 可用入口

- “快速记录任务”打开与顶栏相同的本机快速捕获流程；可粘贴通知并预览字段，也可直接选择“新建空白任务”。
- “工作焦点”显示三个会话级范围：
  - “今日与逾期”：显示今天的六类有效日期事项；逾期只显示未完成任务的截止日期，过去的会议、文件、外出、用章和物资不会被误报为逾期。
  - “未来 7 天”：显示今天之后至第 7 天的有效日期事项，第 8 天不会提前出现。
  - “未排期”：显示没有日期或日期无效的未完成任务及其他业务记录；已完成任务不会出现在这里。
- 工作焦点每个范围最多显示前 8 条，数量仍按当前浏览器已加载的完整数组计算；点击记录会回到原台账并打开右侧只读详情，不在工作台直接编辑、完成或改期。
- “星标记录”独立于日期分桶，显示当前仍为 active 的本机星标；点击后继续复用原台账导航、清除可能隐藏目标的会话筛选并打开原只读详情。没有星标时显示空状态，不会自动创建、编辑或联网。
- “查看完整日历”进入完整的六类日期月视图；工作焦点范围切换只保留在当前页面会话，不写入 IndexedDB、快照或同步服务。
- “记录会议”进入会议管理；进入后仍需点击“新建会议”。
- “登记新文件”进入文件收发模块；进入后仍需点击“登记文件”。
- “打开写作中心”或“开始写作”进入公文写作。
- “导入旧数据”进入数据迁移；所有构建都只在本机解析所选 JSON，不会因选择文件自动上传。

### 6.3 事务日历的日期口径

“事务日历”是独立的只读导航模块。它只汇总当前设备已经加载的六类业务记录，并固定使用下列字段：

| 事项类型 | 日历日期来源 | 显示说明 |
| --- | --- | --- |
| 任务 | 截止日期 `deadline` | 显示“任务截止”、类目和状态 |
| 会议 | 会议时间 `meetingTime` | 显示会议时分和地点/对象 |
| 文件 | 文件日期 `docDate` | 显示收发类型和文号 |
| 外出 | 外出日期 `researchTime` | 显示活动类型和地点 |
| 用章 | 用章日期 `sealTime` | 显示文件类型和用章人 |
| 物资 | 经手日期 `handlerTime` | 显示入库/领用、数量和规格 |

空日期、`2026-02-30` 等无效日期和非四位年份不会进入日历。日历不会改用创建时间或更新时间补齐缺失日期，也不会根据会议通知日期重复生成第二条会议事项。

### 6.4 月视图、筛选和打开记录

- 月视图固定从周一开始，始终显示 6 周、42 个日期格；跨月日期会降低视觉权重，但仍可选择。
- “上一个月”“下一个月”切换月份并选择该月 1 日；“回到今天”同时恢复当前月份和当天。
- “全部 / 任务 / 会议 / 文件 / 外出 / 用章 / 物资”只筛选当前 React 会话中的日历结果。“显示 A / B”中的 A 是筛选后事项总数，B 是六类有效日期事项总数。
- 日期格右上角数字表示当天匹配事项数量，下方短色条表示当天包含的事项类型。当前日期和所选日期拥有不同的可见状态，按钮保留键盘焦点和读屏名称。
- 宽屏在月历右侧显示所选日期议程；窄屏在月历下方显示。点击议程事项会先清除目标台账可能排除该记录的会话筛选，再进入原台账并选中既有只读详情；编辑仍须点击原详情的“编辑此记录”。
- 月份、类型筛选和所选日期不会写入 IndexedDB、localStorage、快照或同步服务。日历不联网、不提醒、不订阅外部日历，也不支持拖拽改期。

## 7. 任务管理

### 7.1 字段说明

| 字段 | 是否必填 | 默认值/选项 | 用途 |
| --- | --- | --- | --- |
| 任务名称 | 必填 | 空 | 列表主标题和周报事项名称 |
| 状态 | 必填 | 未启动；可选未启动、进行中、已完成、已超期 | 表示当前办理状态 |
| 截止日期 | 可空 | 空 | 工作台到期统计和周报下期安排 |
| 工作类目 | 可空 | 日常工作 | 搜索、列表分类和小结上下文 |
| 交办人 | 可空 | 空 | 搜索、列表显示和小结生成 |
| 任务来源 | 可空 | 其他 | 列表来源说明 |
| 交办日期 | 必填 | 新建当天 | 周报素材筛选 |
| 配合单位 | 可多条 | 空 | 记录单位名称及协同状态 |
| 任务阶段 | 可多条 | 空 | 每个阶段可再设置配合单位 |
| 小结模板 | 操作选项 | 进展摘要、协同推进、办结总结 | 确定性生成工作小结 |

| 附件 | 可多项 | 空 | 关联本机文件 |

### 7.2 新建任务

可以从任意非编辑状态点击顶栏“快速记录”、按 `Shift+A`，或在工作台点击“快速记录任务”：

1. 粘贴通知、聊天记录或输入一句任务描述，查看右侧即时识别结果。
2. 点击“继续核对”进入原“新建任务”抽屉；非空但未识别的文字也允许继续手工填写。若不需要带入文字，可点击“新建空白任务”。
3. 原文字会显示在抽屉顶部的“智能识别填单”区域，但不会自动进入备注或任何业务字段；系统只应用已识别的五类字段。
4. 此时抽屉立即显示“未保存修改”。取消、关闭、外侧点击或 Escape 均需确认放弃，确认后原文字和预填内容一起丢弃。

也可以按原路径新建：

1. 进入“任务管理”，点击右上角“新建任务”。
2. 填写“任务名称”。
3. 选择状态。状态不会随日期自动变化。
4. 需要时填写截止日期；交办日期默认为当天，可修改为真实日期。
5. 填写工作类目、任务来源和交办人。
6. 根据需要添加配合单位、任务阶段、工作小结、备注和附件。
7. 点击“保存任务”。
8. 看到“任务已保存，人员和单位已加入常用项”后，返回列表核对名称、状态和截止日期。

任务名称为空、交办日期无效或截止日期不是有效日期时，系统只提示错误，不写入该次修改。

抽屉顶部的“智能识别填单”可以把粘贴的通知文字按本机规则拆成字段：

1. 展开“智能识别填单（粘贴通知文字）”，粘贴微信通知、会议布置或口头记录等文字。
2. 点击“识别并填入”。识别完全在本机执行，不发起任何网络请求。
3. 识别可命中任务名称、交办人、交办日期、截止日期和任务来源；命中的字段会覆盖当前值，提示条会列出本次填入的字段。
4. 识别规则是确定性的文字匹配：形如 `2026-07-21`、`7月28日` 的日期，“截止/期限/×日前完成”判定截止日期，行首日期或“交办/安排”附近日期判定交办日期，“交办人：×”“由×安排”“×主任要求”判定交办人，出现“微信/会议/来文/电话”等关键词时推断任务来源。
5. 识别结果只是草稿预填，可能有误，保存前必须人工核对；未识别出的字段保持原值。

### 7.3 常用人员和单位

- 交办人、承办人、会议接收方、外出参与人员、用章人、审批人和物资经手人共享本机人员常用项；来源单位、发送对象、配合单位和物资来源/领用单位共享单位常用项。
- 在带加号的字段中输入新值后点击加号，可立即写入常用项；保存相应业务记录时也会自动合并已填写的人员和单位。
- 输入框的原生候选通常会按当前文字过滤；其下方“从全部常用项选择”始终列出完整集合。看不到旧值时使用该选择器，不代表旧值已被覆盖。
- 相同文字会去重并按中文排序。当前没有常用项重命名、删除、人员账号或组织架构管理界面。

### 7.4 配合单位

1. 点击“配合单位”右侧的“添加单位”。
2. 输入单位名称，或从常用单位中选择。
3. 选择协同状态：`已通知`、`待反馈`、`进行中`、`已完成`。
4. 可继续添加多行。
5. 点击行末删除按钮只删除当前编辑任务中的这一行，不删除常用单位。
6. 保存任务时，单位名称为空的行会被忽略。

配合单位分组用于把常一起出现的单位存成一键名单：

- “存为分组”把当前名单（去重、去空后）保存为分组，分组存在本机设置库并进入快照备份，最多 50 个单位。
- “按分组添加”选择分组后，把分组成员追加到当前名单末尾：已存在的单位保持原状态和附件不动，只补充缺少的单位，绝不整组覆盖；提示条会说明加入和跳过的数量。
- 任务阶段的配合单位编辑器也可以按分组添加；“存为分组”和“分组管理”（删除分组）只在任务级配合单位区显示。
- 删除分组不影响已加入任务的单位。

### 7.5 任务阶段

1. 点击“添加阶段”。
2. 填写阶段名称。
3. 在该阶段内添加配合单位和状态。
4. 可继续添加其他阶段。
5. 删除阶段会同时移除该阶段编辑区中的配合单位；其他阶段和任务级配合单位不受影响。
6. 保存时，名称为空的阶段和空单位行会被过滤。

### 7.6 一键生成工作小结

1. 先填写任务名称、状态、交办人、配合单位、截止日期和备注。
2. 选择“进展摘要”“协同推进”或“办结总结”。
3. 点击“一键生成小结”。
4. 在“工作小结”中人工核对和修改。
5. 点击“保存任务”。

该操作不调用 AI，只组合当前任务中已经填写的字段。它不会自动判断真实完成比例，也不会补写金额、人数、时间或成效。再次生成会覆盖工作小结输入框中的现有文字，生成前应先复制需要保留的内容。

### 7.7 任务附件

- 公开 Pages、互联网版和内网版都允许添加本机附件；公开 Pages 的附件只保存在当前浏览器 IndexedDB，不会上传到 GitHub Pages。
- 单个附件上限为 8,000,000 字节，超过限制的文件会跳过并提示。
- 文件正文、MIME 类型、大小和 SHA-256 哈希在本机处理，不会因为“选择附件”自动上传。
- 下载图标下载本机附件；按钮禁用表示本机没有可下载正文。
- 解除关联后仍须点击“保存任务”，关联变化才会写入任务。

### 7.8 搜索、编辑和删除

- 搜索框匹配任务名称、工作类目和交办人，不匹配备注、阶段或附件名。
- 点击铅笔图标打开编辑抽屉；修改后必须点击“保存任务”。
- 点击“取消”、关闭按钮、抽屉外区域或按 Escape 时，如存在未保存修改会先要求确认；选择继续编辑则保留当前字段和暂存附件，确认放弃后才关闭并清理暂存内容。
- 点击删除按钮后必须确认；确认后任务进入回收站，可恢复或再永久删除。
- 从旧系统导入的任务若含未映射字段，编辑抽屉会出现“查看迁移原始字段”；该内容只读显示。

## 8. 会议管理

会议管理用于形成可检索的会议通知和参会台账。它不是日历提醒系统，不会在会议前自动弹窗、发短信或发送邮件。

### 8.1 字段说明

| 字段 | 是否必填 | 默认值/选项 | 用途 |
| --- | --- | --- | --- |
| 会议主题 | 必填 | 空 | 列表主标题、搜索和周报会议事项 |
| 发送对象 | 可空 | 空，可选择常用单位 | 记录通知发送到的单位或群体 |
| 接收方 | 可空 | 空，可选择常用人员 | 记录实际接收人或联系人 |
| 通知日期 | 可空 | 新建当天 | 记录通知动作并参与周报日期筛选 |
| 会议时间 | 可空 | 空，精确到分钟 | 记录实际开会时间并参与周报日期筛选 |
| 会议地点 | 可空 | 空 | 列表显示和搜索 |
| 备注 | 可空 | 空 | 记录议题、准备事项或其他已核实说明 |
| 附件 | 可多项 | 空 | 会议通知、议程等本机文件 |

### 8.2 新建或编辑会议

1. 进入“会议管理”，点击“新建会议”。
2. 填写会议主题。
3. 填写发送对象和接收方；可点击加号加入常用项，也可从完整常用项列表选择。
4. 核对通知日期；需要时填写会议时间和地点。
5. 填写备注并选择附件。
6. 点击“保存会议”，看到成功提示后回到列表核对。

只有会议主题是必填项。通知日期和会议时间可以为空，但已填写值必须在 `1900` 至 `9999` 年范围内且是有效日期/时间。会议时间使用本机时区的本地时间文本，当前不保存独立时区信息。

### 8.3 搜索、附件和删除

- 搜索匹配会议主题、发送对象、接收方和会议地点，不匹配备注或附件名。
- 点击铅笔图标编辑；任何字段、附件关联变化都要点击“保存会议”才会写入会议记录。
- 点击删除按钮后必须确认；确认后会议进入回收站且附件仍可下载。只有在回收站永久删除后，不再被其他记录引用的会议附件才会清理。
- 周报会在会议时间、通知日期、创建时间或更新时间落入所选范围时纳入该会议。

## 9. 文件收发

### 9.1 字段说明

| 字段 | 是否必填 | 默认值/选项 | 用途 |
| --- | --- | --- | --- |
| 文件标题 | 必填 | 空 | 列表主标题和周报文件事项 |
| 文件类型 | 必填 | 收文；可选收文、发文、其他 | 文件方向分类 |
| 成文日期 | 必填 | 新建当天 | 列表显示和周报素材筛选 |
| 发文字号 | 可空 | 空 | 搜索和文件识别 |
| 来源单位 | 可空 | 空 | 搜索、列表和常用单位 |
| 承办人 | 可空 | 空 | 常用人员和办理责任记录 |
| 登记状态 | 必填 | 待登记；可选待登记、已登记、已办结、归档 | 办理状态 |
| 安全级别 | 可空 | 公开 | 自由文本提示，不是访问控制 |
| 工作类目 | 可空 | 空 | 工作分类 |
| 文件归类 | 可空 | 空 | 文件台账分类 |
| 发送范围 | 可空 | 空 | 记录实际发送对象范围 |
| 备注 | 可空 | 空 | 补充已核实情况 |
| 附件 | 可多项 | 空 | 关联本机文件 |

“安全级别”只是记录字段，不会加密文件，也不会自动限制其他本机用户访问。

### 9.2 登记文件

1. 进入“文件收发”，点击“登记文件”。
2. 填写文件标题并选择文件类型。
3. 核对成文日期。
4. 填写发文字号、来源单位和承办人。
5. 选择登记状态。
6. 按实际情况填写安全级别、工作类目、文件归类、发送范围和备注。
7. 展开“关联任务”，可按任务名称、类目、来源、交办人或截止日期在本机筛选，并勾选一个或多个 active 任务。
8. 需要时选择附件。
9. 点击“保存文件”，返回列表核对。

文件标题或成文日期不合格时不会保存。关联选择没有独立保存按钮；只有点击“保存文件”才会与文件字段一起持久化。旧快照或跨设备同步可能留下当前不可用的弱引用，编辑器会明确显示数量；可保留等待回收站恢复，也可点击“清理不可用关联”后再保存。清理是显式操作，详情读取不会自动改写文件。

### 9.3 搜索、编辑、删除和附件

- 搜索框匹配文件标题、发文字号和来源单位，不匹配承办人、备注或附件名。
- 点击铅笔图标编辑，点击“保存文件”后才会持久化。
- 文件详情会按保存顺序显示当前 active 关联任务；任务详情从当前已加载 active 文件数组反向显示关联文件。点击关联项会清除目标台账可能隐藏记录的会话筛选，进入原模块并选中原只读详情，不形成第二套详情或编辑器。
- 点击删除按钮后必须确认；确认后文件进入回收站，可恢复或再永久删除。
- 文件或任务移入回收站后，active 详情暂时隐藏该关系；恢复后只要文件中的任务 ID 仍保留，关系自动重新显示。永久删除或缺失目标只会被忽略，不会把标题、正文或附件复制进另一侧记录。
- 附件上限、下载和解除关联规则与任务附件一致。
- 从旧系统导入的文件若含未映射字段，可在编辑抽屉中只读查看迁移原始字段。

## 10. 外出活动

外出活动用于记录调研、外出开会、一般活动、慰问和上级来访。它保存活动事实与成果，不代替请示审批、车辆调度或考勤系统。

### 10.1 字段说明

| 字段 | 是否必填 | 默认值/选项 | 用途 |
| --- | --- | --- | --- |
| 活动日期 | 可空 | 新建当天 | 列表显示和周报日期筛选 |
| 活动类型 | 必填 | 外出调研；另有外出开会、外出活动、慰问活动、上级来访 | 业务分类和搜索 |
| 活动主题 | 必填 | 空 | 列表主标题、搜索和周报事项 |
| 活动地点 | 可空 | 空 | 列表显示和搜索 |
| 是否用车 | 可空 | 未选择、是、否 | 记录用车事实，不触发调度 |
| 参与人员 | 可空、多名 | 空，多人建议用顿号分隔 | 列表、搜索和常用人员沉淀 |
| 活动内容摘要 | 可空 | 空 | 记录过程；没有成果时作为列表摘要和周报素材 |
| 成果记录 | 可空 | 空 | 优先作为列表摘要和周报成果 |
| 备注 | 可空 | 空 | 补充已核实信息 |
| 附件 | 可多项 | 空 | 调研材料、照片或纪要等本机文件 |

### 10.2 新建或编辑外出活动

1. 进入“外出活动”，点击“新建外出活动”。
2. 核对活动日期并选择活动类型。
3. 填写活动主题、地点和是否用车。
4. 在“参与人员”中用顿号、逗号、分号或换行分隔多人；也可从完整常用人员列表逐人追加。
5. 填写内容摘要、成果记录和备注，按需添加附件。
6. 点击“保存活动”，回到列表核对类型、人员、地点和成果。

保存时活动主题不能为空。参与人员会拆分、去空并合并到常用人员；从选择器追加同名人员时会去重。系统不校验人员是否重复参加其他活动。

### 10.3 搜索、周报和删除

- 搜索匹配主题、活动类型、参与人员、地点和内容摘要；当前不单独匹配成果记录、备注或附件名。
- 列表优先显示成果记录；成果为空时显示内容摘要。
- 周报在活动日期、创建时间或更新时间落入范围时纳入记录。
- 点击删除按钮后必须在确认框中确认；取消不会改变记录。确认后活动进入回收站，可恢复或再永久删除。
- 软删除保留活动附件；永久删除时只清理该活动曾引用、且已不再被其他 active/trash 业务记录或历史档案引用的附件，共享附件会保留。

## 11. 用章管理

用章管理是经办台账，不是电子签章、印章控制设备或审批流。只有在单位既定审批程序完成后，才应如实登记审批人和所盖文件。

### 11.1 字段说明

| 字段 | 是否必填 | 默认值/选项 | 用途 |
| --- | --- | --- | --- |
| 用章日期 | 可空 | 新建当天 | 列表显示和周报日期筛选 |
| 用章人 | 必填 | 空，可选常用人员 | 实际经办人 |
| 审批人 | 必填 | 空，可选常用人员 | 已完成审批的责任记录 |
| 所盖文件名称 | 必填 | 空 | 列表主标题、搜索和周报事项 |
| 文件类型 | 可空 | 请示、报告、通知、函、合同、证明、申请、其他 | 分类和搜索 |
| 备注说明 | 可空 | 空 | 记录份数、用途等已核实说明 |
| 附件 | 可多项 | 空 | 审批单或佐证材料的本机副本 |

### 11.2 新建或编辑用章记录

1. 进入“用章管理”，点击“新建用章记录”。
2. 核对用章日期。
3. 填写用章人和审批人；可加入或选择常用人员。
4. 填写所盖文件名称并选择文件类型。
5. 填写备注说明，按需添加审批佐证附件。
6. 点击“保存用章”，回到列表核对。

用章人、审批人和所盖文件名称缺一不可。系统只验证这些字段是否填写，不会验证审批权限、印章真伪、文件份数或实际盖章动作。

### 11.3 搜索、附件和删除

- 搜索匹配所盖文件名称、用章人、审批人和文件类型，不匹配备注或附件名。
- 周报在用章日期、创建时间或更新时间落入范围时纳入记录。
- 编辑后必须点击“保存用章”；删除需要确认，确认后进入回收站，可恢复或再永久删除。
- 佐证附件只保存在本机；内网版只有主动同步后才会传到已配置的私有服务端。

## 12. 物资收发

物资收发使用流水账方式记录入库和领用，并按“物资名称 + 规格”计算当前账面库存。它不包含采购审批、金额、批次、保质期或实物盘点。

### 12.1 字段说明

| 字段 | 是否必填 | 默认值/选项 | 用途 |
| --- | --- | --- | --- |
| 物资名称 | 必填 | 空 | 库存键、列表主标题和搜索 |
| 规格 | 可空 | 空 | 与物资名称共同组成库存键 |
| 数量 | 必填 | 1，正整数 | 入库增加或领用减少库存 |
| 收发类型 | 必填 | 入库；可选入库、领用 | 决定数量正负方向 |
| 经手日期 | 可空 | 新建当天 | 列表显示和周报日期筛选 |
| 经手人 | 可空 | 空，可选常用人员 | 经办记录和搜索 |
| 来源/领用单位 | 可空 | 空，可选常用单位 | 入库来源或领用去向 |
| 备注 | 可空 | 空 | 补充批次或用途等说明 |
| 附件 | 可多项 | 空 | 收据、领用单等本机文件 |

### 12.2 新建入库或领用记录

1. 进入“物资收发”，点击“新建物资记录”。
2. 填写物资名称和规格。相同物资应始终使用完全一致的名称和规格。
3. 填写正整数数量并选择“入库”或“领用”。
4. 核对经手日期，填写经手人和来源/领用单位。
5. 填写备注并按需添加附件。
6. 点击“保存物资”，在列表查看该名称和规格对应的账面库存。

### 12.3 库存计算与风险

- 库存键是去除首尾空格后的“物资名称 + 规格”。不同大小写、全半角、内部空格或不同规格会形成不同库存项。
- 每笔入库增加数量，每笔领用减少数量；编辑或移入回收站后，列表会根据全部 active 流水重新计算。恢复后重新计入库存，永久删除后不再恢复。
- 搜索只过滤当前列表，库存仍按全部物资记录计算，不会只按搜索结果计算。
- 当前允许账面库存变为负数，不会阻止超额领用，也没有盘点调整单。出现负数时应先核对漏登入库、名称/规格不一致和误录数量。
- 搜索匹配物资名称、规格、经手人和来源/领用单位；不匹配备注或附件名。
- 周报在经手日期、创建时间或更新时间落入范围时纳入该流水。

## 13. 常用项管理

“常用项管理”把单位与机关处室、人员分成两个独立列表。它只维护各业务表单的候选项，不会改写已经保存的任务、会议、文件、外出、用章或物资记录。

### 13.1 新增和编辑

1. 在“单位与处室”或“人员”面板顶部输入新值，点击“添加”或按 Enter。
2. 直接修改列表中的文字即可重命名；空白值和重复值会在保存时清理、去重并排序。
3. 修改只存在于当前页面草稿中，必须点击“保存全部修改”才会写入本机设置库。

### 13.2 删除和业务影响

- 点击某行末尾的删除按钮只移除该候选项，不删除或改写引用旧文字的历史业务记录。
- 保存后，新建或编辑业务记录时的“从全部常用项选择”会立即使用新列表。
- 常用项随本地快照备份，但不进入内网同步；需要在另一设备复用时应导出并恢复快照。

## 14. 公文写作

公文写作页面分为三栏：左侧选结构，中间编辑正文，右侧查看校核提醒。手机窄屏会按页面布局纵向排列。

### 14.1 选择和套用模板

1. 在“结构选择”搜索框输入文种或模板名称。
2. 查看模板下方的来源类型和版本。
3. 点击模板。
4. 系统立即把模板标题和结构载入主草稿。
5. 在中间纸张区域修改标题和正文。

当前知识包包含工作总结、工作计划、工作简报、工作报告、工作通知、会议通知、工作方案、调研报告、会议纪要、新闻稿和对照检查材料等结构。模板来源分为：

- 官方规范：确定性格式依据。
- 单位模板：演示或单位内部结构。
- 授权教材建议：授权范围内的写作建议。
- 本机自定义：由当前用户保存，不进入公开知识包。

点击另一个模板会直接替换当前编辑器内容，没有确认框。切换前应先保存版本、导出 DOCX 或复制需要保留的正文。

### 14.2 编辑和“落笔检查”

- 标题在纸张顶部单独编辑，正文在富文本区域编辑。
- 当前编辑器支持段落、标题、列表、引用、粗体、斜体等基础结构，但页面没有完整 Word 式排版工具栏。
- “文稿标题”检查标题是否为空。
- “结构完整”按有效文本行数判断，达到 3 行即通过，不等于内容已经完整。
- “句子节奏”提示超过 45 个字符的文本行，属于写作建议。
- “事实待核”始终提醒人工核对数据、时间和单位。
- 下方规则显示来源、版本和严重程度；规则只提示，不会自动改写正文。

### 14.3 导入 DOCX、HTML 或 TXT

1. 点击“导入文档”。
2. 选择 `.docx`、`.html`、`.htm` 或 `.txt` 文件。
3. 等待导入提示。
4. 核对自动取得的标题、正文结构和转换警告。
5. 修改后点击“保存版本”。

导入规则：

- 单个文件不能超过 10,000,000 字节。
- DOCX 使用 Mammoth 在本机提取语义结构。
- HTML 会删除脚本、样式、表单、iframe、对象、SVG、事件属性和未知标签，只保留允许的文本结构。
- TXT 把非空行转换为段落并转义 HTML 特殊字符。
- 导入后的第一行不超过 80 个字符时用作标题；否则使用文件名。
- 页眉页脚、复杂表格、文本框、批注、精确分页、精确字体和 Word 特有版式可能丢失。
- 导入只替换当前内存中的主草稿；用户仍须点击“保存版本”才会持久化。

### 14.4 保存主草稿

- 点击“保存版本”会先通过原主草稿保存路径写入当前内容、把版本号加 1，再为刚保存成功的内容记录一条本机历史。新安装的未保存草稿显示版本 0，第一次显式保存得到 v1；已有草稿沿用原版本号。
- 当前仍只有一份主草稿记录，版本历史不是第二份主草稿，也不会形成第二套保存入口。
- 主记录已经保存但历史写入失败时，页面会明确提示“文稿已保存，但版本历史记录失败”；不能把历史失败误报成主记录保存失败。
- 在同一页面内切换模块后返回，未保存内容通常仍在当前 React 会话；刷新、关闭页面或应用退出后不能保证保留。
- 进行大改、导入文档或切换模板前，建议先导出 DOCX 或本地快照。

### 14.5 查看、恢复和删除主草稿历史

1. 至少保存一次主草稿，然后点击“版本历史”。
2. 在左侧按保存时间从新到旧选择版本；右侧以只读纯文本并排显示“当前内容”和“该版本内容”，不会执行历史 HTML。
3. 点击“恢复 vN 为未保存工作副本”，并确认替换当前屏幕中尚未保存的内容。
4. 恢复后原主草稿 ID、当前保存版本号和历史链均保持不变；工具栏持续显示“未保存工作副本 · 来自 vN”。刷新页面会重新载入恢复前的已保存版本。
5. 确认内容无误后，仍使用页面原“保存版本”按钮写入下一版；没有“直接覆盖为此版本”的第二套保存按钮。

历史列表支持确认后删除单条旧版本或清空当前主草稿历史。当前保存版的单条删除按钮不可用，删除历史不会改写当前标题、正文或模板引用。Escape、右上角关闭按钮和点击对话框外侧都可关闭，关闭后焦点返回“版本历史”入口；对话框打开期间全局查找、快速记录和当前页 AI 面板不会叠加。

本机历史统一受以下上限约束：每条完整序列化快照最多 1,000,000 字符；每个主草稿或周报目标最多 20 条；当前设备全局最多 100 条；全部历史快照合计最多 10,000,000 字符。超过上限时按保存时间和不可预测历史 ID 确定性裁剪最旧记录。历史作为 `setting` 进入本地快照，但不进入私有同步、全局查找、AI 材料、Cookie、localStorage、日志、URL 或网络请求。

### 14.6 保存、重命名、删除和复用自定义格式

1. 准备好标题和正文；两者不能为空。
2. 点击“保存自定义格式”。
3. 保存成功后，该格式出现在左侧模板列表中，来源显示“本机自定义”。
4. 以后点击该格式，会重新载入当时保存的标题和正文结构。

每次点击“保存自定义格式”仍会创建一条新格式，不会覆盖同名或当前选中的格式。自定义格式会进入本地快照，但不会自动公开、上传或参与内网同步。

重命名本机自定义格式：

1. 在左侧找到目标格式；可以先用“搜索写作模板”缩小列表。
2. 点击该行右侧的铅笔图标“重命名自定义格式”。
3. 在行内输入新名称。名称会去除首尾空白，不能为空，最多 80 个字符。
4. 按 Enter 或点击对勾保存；按 Escape 或点击叉号取消。取消不会改变原名称。
5. 保存后仍是同一个格式，原正文、结构、创建时间和来源不变；刷新后新名称继续保留。

删除本机自定义格式：

1. 点击该行右侧的删除图标“删除自定义格式”。
2. 阅读确认框；选择取消不会删除，选择确认后无法撤销。
3. 删除后，该格式从本机设置和后续快照中移除，不进入六类业务回收站。

重命名和删除按钮只对“本机自定义”格式显示。官方规范、单位模板和授权教材建议等知识包格式保持只读。删除当前正在套用的格式不会清空或改写当前标题、正文、文种、版本和已经保存的文稿；系统只解除当前草稿对该格式的关联，之后可以继续编辑、保存版本或另存为新格式。这两项管理操作只访问当前设备的本机设置库，不会发起网络请求。

### 14.7 导出 DOCX 和 PDF

- “导出 DOCX”导出当前编辑器内容，即使尚未点击“保存版本”也可以导出。
- DOCX 使用 A4 文档模型，并写入作者元数据 `HaoXiangHwang`。
- 桌面端“导出 PDF”打开系统保存对话框。
- Web 端“导出 PDF”打开浏览器打印界面，应选择“另存为 PDF”、A4 纸张，并检查边距和缩放。
- 系统不捆绑无明确授权的中文字体。缺少方正小标宋、仿宋、黑体或楷体时会使用本机回退字体。
- 正式发文前必须在目标 Word/PDF 阅读器中检查标题层级、字体、页边距、分页、空白页和附件说明。

### 14.8 写作与 AI 的关系

AI 配置集中在“AI 助手”模块；公文写作页的“AI 润色”按钮会在当前页面打开 AI 协作面板，把当前标题和正文作为自定义材料并预设“公文润色”。脱敏、逐次确认和只读结果都在该面板完成，页面仍停留在“公文写作”。需要采用时，应人工核对后使用“复制结果”，并再次执行确定性规则和事实审核。

## 15. 周报生成

### 15.1 默认范围和素材选择

- 新建周报默认范围是本周一至当天。
- 任务在交办日期、截止日期、创建时间或更新时间落入范围时会被选中。
- 未完成且与选择区间有时间交集的任务也可能被选中。
- 文件在成文日期、创建时间或更新时间落入范围时会被选中。
- 会议在会议时间、通知日期、创建时间或更新时间落入范围时会被选中。
- 外出活动、用章和物资分别按业务日期、创建时间或更新时间筛选。
- 历史档案、自定义格式、Skill、配置和附件不会单独成为周报素材。

生成的默认正文包含“总体情况、重点进展、文件办理、会议与外出活动、用章与物资保障、下期安排”六部分。任务优先引用工作小结；工作小结为空时使用任务状态。会议、外出、用章和物资只组合已录入字段。系统不会从未录入字段推断金额、人数、成效或责任结论。

### 15.2 生成周报

1. 进入“周报生成”。
2. 设置开始日期和结束日期，开始日期不得晚于结束日期。
3. 点击“重新汇总”。
4. 核对左侧任务、文件、会议、外出、用章和物资六类素材数量。
5. 修改周报标题和正文，补充已经核实的事实。
6. 点击“保存版本”。
7. 使用“复制正文”“导出 DOCX”或“导出 PDF”。

左侧“来源记录”会列出当前周报保存的六类素材引用。按钮只打开当前本机仍为 active 的记录详情，不是周报保存时的内容快照；点击后会复用原台账导航并清除可能隐藏目标的会话筛选。回收站、永久删除、缺失或不在本机的引用不会显示标题，只显示不可用数量。周报有未保存修改时，打开来源前会要求确认；取消确认会留在周报编辑器，确认后未保存内容会被放弃。

“重新汇总”会重新生成默认标题和正文，覆盖当前手工编辑内容，同时保留当前周报 ID 和版本号，直到再次保存。重新汇总前先复制需要保留的手工内容。

### 15.3 新建、保存、打开和删除

- “新建”返回本周一至当天的未保存草稿；当前未保存修改不会自动另存。
- 新周报第一次保存时创建记录并显示在“已保存周报”中。
- 再次保存同一周报会增加版本号、更新当前周报记录，并为刚保存的标题、日期、正文和六类来源 ID 数组记录一条本机历史。每份周报的历史按 report ID 隔离，不会混入其他周报。
- 点击左侧已保存周报可重新打开。
- 已保存周报可点击“版本历史”使用与主草稿相同的只读对比、非破坏恢复、单条删除和清空操作。恢复只载入原周报编辑器并持续显示未保存状态；再次点击原“保存版本”后才形成更高版本。
- 删除按钮会先请求确认；取消确认时当前未保存编辑和列表选择保持不变。确认后删除该周报记录及其本机历史，没有回收站。
- 历史系统导入的旧周报不进入这个列表，仍在“历史档案”中只读保存。
- 导出使用屏幕上当前内容，不要求先保存；需要留存阶段稿时可先导出 DOCX。

### 15.4 周报模板

“周报生成”页底部提供“章节结构管理”，模板决定周报的章节顺序、标题和数据来源：

- 数据来源分七类：总体数字、任务进展、文件办理、会议与外出、用章与物资、下期安排六类自动章节仍由本机记录确定性汇总；“手工填写”章节只插入占位提示，不会编造事实。
- 在“汇总设置”的“周报模板”下拉选择模板后点击“重新汇总”，章节编号按模板顺序自动生成（一、二、三……）。
- 编辑器支持增删章节、上下移动、改标题和占位提示，最多 20 个章节；“载入默认结构”可回到内置六章结构。
- “导出 JSON / 导入 JSON”用于在设备间复制模板；导入时会校验章节数量、标题长度和来源类型。
- “从范文提取结构”在本机识别粘贴范文中“一、……”“（一）……”样式的标题并推断数据来源，不发起任何网络请求；无法对应自动汇总的章节会设为“手工填写”并附范文该节开头。提取结果需检查后手动保存。
- 模板保存在本机设置库并进入快照备份，不参与内网同步；已保存周报的正文不会因模板修改而变化。

## 16. 统计分析

“统计分析”把六类 active 业务台账按月份汇总成确定性数字：回收站和永久删除墓碑不参与统计；全部数据来自本机已录入记录，不联网、不估算、不写入任何记录。

### 16.1 筛选与口径

- “统计月份”下拉列出所有出现过记录的月份和当前月份；选择“全部时间”查看累计数字。
- “任务类目”下拉列出任务中出现过的类目，只影响任务类指标，不影响类目对比图和六类台账计数。
- 任务按交办日期归入月份（缺交办日期时按创建日期）；会议按会议时间或通知日期，文件按成文日期，外出、用章、物资按各自业务日期，缺失时都回退到创建日期。

### 16.2 指标含义

| 指标 | 计算方式 |
| --- | --- |
| 本期任务 | 归入所选月份（及类目）的任务总数，备注中给出进行中与未启动数量 |
| 本期新建 | 创建时间在所选月份内的任务数量 |
| 已完成 | 本期任务中状态为“已完成”的数量 |
| 已超期 | 本期任务中状态为“已超期”，或已过截止日期仍未完成的数量 |

### 16.3 图形说明

- “类目对比”用单色横条比较各类目的任务数量，超过 9 类时其余合并为“其他”；数字直接标注在条旁。
- “完成情况”用一根分段条显示未启动、进行中、已完成、已超期四种状态的占比，并配有图例、数量和百分比；分段条只按记录的当前状态统计。
- “同期台账”列出同月份的会议、文件、外出、用章和物资入库/领用笔数。
- “类目对比”条与任务列表的类目圆点默认按类目名称确定性分配四档色板（荧光黄、草绿、紫色、中性灰）；在“类目配色”中可为单个类目固定颜色或恢复自动，设置保存在本机设置库并进入快照备份。
- 图形不使用第三方图表库和远程资源；`prefers-reduced-motion` 下无动画依赖。

## 17. 回收站

回收站只显示任务、会议、文件、外出、用章和物资六类已软删除记录。它不是历史档案：历史档案保存迁移原件且始终只读；回收站保存当前应用中可恢复的业务记录。

### 17.1 查找和筛选

- 搜索框匹配记录标题、列表摘要和附件名，不匹配附件正文。
- “类型”筛选可选择全部、任务、会议、文件、外出、用章或物资；右侧显示当前可见数和回收站总数。
- 列表显示记录类型、标题、摘要、删除时间以及仍被该记录引用的附件。点击附件名称可下载；按钮禁用表示本机缺少正文。
- 回收站、筛选、附件下载和恢复操作不会联网，也不会把视图状态写入 IndexedDB 或快照。

### 17.2 恢复记录

1. 找到目标记录，点击“恢复”。
2. 在确认框核对标题并确认。
3. 返回原业务模块，核对字段、日期、附件和列表统计。
4. 如使用内网同步，主动点击“同步全部业务数据”，把新的恢复状态传给私有服务端。

恢复会保留软删除前的完整业务字段和附件引用，只移除删除标记并刷新更新时间。记录恢复后重新进入工作台、日历、统计、周报、AI 材料和全局业务搜索的 active 集合。

### 17.3 永久删除和清空

- “永久删除”只处理当前一条记录；“清空回收站”处理当前回收站全部记录。两者都会显示明确确认，并且无法通过应用恢复。
- 永久删除后只留下四字段最小同步墓碑，快照和私有同步中都不再包含业务正文或附件 ID。
- 系统只清理不再被其他 active/trash 业务记录或历史档案引用的附件。若同一附件仍被另一条记录或迁移原件引用，不会误删。
- 私有同步仍会传输最小墓碑；服务端或其他设备上的旧版本只要更新时间更早，就不能覆盖墓碑并复活记录。系统没有后台自动同步，仍需用户显式点击同步。
- 不提供自动 30 天清理。长期保留还是永久删除由用户明确决定，避免离线设备在未知时间自动丢失资料。

## 18. 历史档案

### 18.1 可以查看什么

历史档案保存旧系统中未映射为新任务或文件的原件，包括：

- 会议记录；
- 外出、调研或活动记录；
- 用章记录；
- 物资收发记录；
- 旧周报；
- 未识别类型；
- 历史 Skill 和配置。

列表显示类型、标题、摘要、日期和来源版本。页面下方单独显示历史 Skill 与配置。

### 18.2 查看原始字段和附件

- 点击“查看迁移原始字段”展开 `legacyPayload` 的格式化 JSON。
- 历史 HTML、Skill 内容和配置只作为纯文本显示，不作为 HTML 或脚本执行。
- 历史附件同时有本机正文和 SHA-256 哈希时可下载。
- 按钮禁用表示迁移数据只有附件引用，缺少可验证的正文或哈希。

### 18.3 只读与复制规则

历史档案本身不能编辑、删除或搜索。会议、外出、用章和物资类型会显示“复制为新记录”：

1. 点击历史原件下方的“复制为新记录”。
2. 系统进入对应可编辑模块并打开预填抽屉。
3. 核对必填字段、日期、枚举值、附件和“查看迁移原始字段”。旧值不合法时可能被留空，需要人工补充。
4. 点击该模块的保存按钮，创建一条新 ID 的可编辑记录。
5. 返回历史档案确认原件仍然存在且未改变。

复制会保留来源版本、原始字段和可用附件引用，但不会自动保存。旧周报和未知类型没有复制按钮；需要续办时人工新建任务或相关业务记录，并在备注中写明历史来源。不得通过修改快照绕过只读边界。

## 19. 数据迁移、备份与恢复

### 19.1 哪些版本允许导入

- 公开 Pages：允许导入历史业务 JSON 和恢复快照，全部只在当前浏览器解析并写入 IndexedDB，不会上传到 Pages 或私有 API。
- 互联网 Web/桌面版：允许导入和恢复，数据只在本机解析。
- 内网 Web/桌面版：允许导入和恢复；导入本身不会自动同步到服务器，仍须建立会话后主动同步。

### 19.2 支持的文件

系统自动识别：

1. `升级版04.html` 对应旧系统导出的 JSON；
2. `wenxibuddy0722.html` 对应旧系统导出的 JSON；
3. `format` 为 `hxhwang-gw-local-v1` 的本地快照。

不要选择旧 HTML 文件本身，也不支持 ZIP、Excel、Word 或任意 JSON。两份旧导出都可能使用相同来源标记，迁移报告会保留“不足以精确区分版本”的警告，不会伪造来源。

### 19.3 导入旧数据

1. 先导出当前本地快照。
2. 进入“数据迁移”。
3. 把 JSON 文件拖到“导入 JSON / 快照”区域，或点击该区域选择文件。
4. 等待迁移完成。
5. 查看来源版本、各类导入数量、附件数量和全部警告。
6. 进入六类业务台账和历史档案抽查名称、日期、原始字段和附件。
7. 对照旧系统原始数量，记录无法导入或缺正文的项目。

导入不会先清空本机数据：

- 同 ID、同类型记录按导入内容更新。
- 同一个 ID 已被另一种记录类型占用时，系统拒绝跨类型覆盖。
- 快照中重复 ID 会跳过并写入警告。
- 空 Skill、悬空附件和来源版本歧义可能产生警告。
- 旧导出默认未必包含全部 Skill；报告中的缺失提示应保留。

### 19.4 导出本地快照

1. 点击“导出快照”。
2. 浏览器下载 `hxhwang-gw-本地快照-YYYY-MM-DD.json`。
3. 打开文件，确认存在 `format`、`exportedAt`、`author` 和 `records`。
4. 把文件复制到受控备份位置。
5. 定期在测试浏览器配置或备用设备中执行恢复抽查。

快照包含任务、会议、文件、外出、用章、物资、附件、主草稿、周报、历史档案、AI 历史、常用项、自定义格式、星标记录引用和其他本机设置。星标引用会在写入和恢复时规范化，只允许六类模块、记录 ID 和星标时间；额外标题、备注、API Key 或未知字段不会保留。快照不包含互联网 API Key、一次性访问码、会话令牌、服务端模型密钥或数据库连接串。

### 19.5 恢复快照

1. 在支持导入的版本中点击“选择 JSON 文件”。
2. 选择 `hxhwang-gw-local-v1` 快照。
3. 等待“本地快照恢复完成”。
4. 查看迁移报告和警告。
5. 逐个模块抽查；不要只看记录总数。

恢复是合并/更新操作，不会自动删除当前快照中没有的本机记录，也不会先清空数据库。单个快照最多接受 50,000 条记录；无效 ID、未知类型、无效载荷、重复 ID 和跨类型冲突会被跳过并记录警告。

### 19.6 建议备份时点

- 首次正式录入后；
- 导入旧数据前后；
- 批量删除前；
- 大幅修改文稿或周报前；
- 升级、切换互联网/内网版或更换设备前；
- 清理浏览器缓存、站点数据或桌面客户端用户目录前。

## 21. 公开 Pages 与互联网版 AI

### 21.1 使用条件

- 可在公开 Pages、互联网 Web 和互联网桌面版使用。
- 请求地址必须使用 HTTPS；本机调试例外允许 `http://127.0.0.1:端口` 或 `http://localhost:端口`。
- 地址不得包含用户名或密码。
- 模型服务必须提供 OpenAI 兼容的 `/v1/models` 和 `/v1/chat/completions`。
- 公开 Pages 和浏览器互联网版还要求服务商允许当前页面来源进行 CORS 请求；互联网桌面版通过受限 Electron IPC 请求，不受浏览器 CORS 同等限制。

### 21.2 选择服务商并获取模型

1. 进入“AI 助手”。
2. 选择服务商预设。当前内置 OpenAI、DeepSeek、Moonshot/Kimi、智谱 GLM、阿里云百炼/DashScope、SiliconFlow、本机 Ollama 和自定义兼容接口；默认选择 DeepSeek。
3. 核对“请求地址”。地址可写到站点根路径、自定义代理路径或以 `/v1`、`/v4` 等版本号结尾的路径；以版本号结尾时系统直接拼接资源名，不会重复拼接 `/v1`。
4. 除本机 Ollama 等无需鉴权的接口外，填写 API Key。Key 只保留在当前 React/Electron 会话内存中。
5. 点击“获取 AI 模型”。这是第一次主动网络请求。请求期间按钮显示“正在获取模型”并阻止同一配置重复提交；修改服务商、地址或 Key 后可以立即发起新请求，旧配置迟到的响应不会覆盖当前列表。
6. 已有模型目录时按钮改为“刷新 AI 模型”。刷新期间上次成功目录和当前选择继续可用，点击“停止等待”会结束本次等待；浏览器会中止 Fetch，桌面版会停止等待并忽略迟到 IPC。刷新失败或取消不会清空目录，成功后按服务商返回顺序整体更新；当前模型仍存在时继续保留，否则回到新目录第一项。
7. 从返回列表选择模型；获取列表为空时不能发送生成请求。模型超过 8 个时可按模型 ID 关键词在本机筛选，顺序保持服务商返回顺序；筛选无匹配时当前模型仍保留，点击“清除模型筛选”恢复完整列表。筛选本身不联网，也不进入本地存储。模型就绪后连接配置会自动收起，若要更换地址、Key、服务商或模型，点击“兼容 API 配置”摘要重新展开。

只选择预设、填写地址和 Key 不会自动联网。在模块间切换不会丢失当前会话中的 Key；关闭或刷新页面后需要重新填写 Key。系统不内置任何真实 Key；API Key 不写入 IndexedDB、快照、URL、配置文件或应用日志。自定义地址不得包含用户名或密码。

### 21.3 载入材料、生成脱敏预览并发送

1. 选择处理用途：任务总结、综合工作总结、周报润色、公文润色、提纲生成或自定义处理。
2. 选择本机素材：当前公文草稿、全部未完成任务、最近保存的周报、全部业务台账摘要或自定义材料。
3. 非“自定义材料”点击“载入素材”；自定义材料直接粘贴或输入。从公文写作或周报生成页点击“AI 润色”时，当前文本会在当前页面 AI 协作面板中自动载入。自动载入最多取前 120,000 个字符；手工粘贴超过 120,000 个字符时系统拒绝生成脱敏预览，应先缩小材料范围。
4. 点击“生成脱敏预览”。该步骤只在本机执行，不请求模型。
5. 人工逐行检查脱敏预览，并在预览框中继续删除或替换敏感内容。
6. 核对服务商、模型、用途和最终发送文字。
7. 勾选“我确认本次材料已脱敏、非涉密且允许发送到所选服务商”。修改材料、用途、地址、服务商、模型或 Key 后，应重新选择模型并取消后重新勾选确认，不要复用旧确认状态。
8. 点击“确认本次 AI 请求”。按钮会切换为“正在生成结果”并禁用，避免重复点击产生多次付费请求；需要放弃本次等待时可点击“停止等待生成结果”。
9. 生成期间上一条成功结果继续可见。只有仍属于当前材料、用途、模型和连接配置的成功响应才会一次性替换结果并保存一条本机历史；停止等待、修改相关输入、导航离开或组件卸载后，迟到响应不会写入结果或历史。
10. 成功、失败、停止等待或相关输入变化后，确认框都会取消勾选；再次发送前必须重新检查脱敏预览并逐次确认。

本地脱敏会尝试替换：

- 18 位身份证号；
- 中国大陆常见 11 位手机号；
- 常见邮箱地址；
- 带“姓名、联系人、承办人、经办人”标签的 2 至 8 位中文姓名。

它不会识别所有地址、单位内部编号、罕见号码、上下文身份、商业秘密或隐含敏感关系。看到脱敏预览不等于材料已经匿名化。

### 21.4 返回结果和限制

- 标准 OpenAI 兼容响应会先显示可读正文和字段变化摘要，可用“复制结果”复制正文，并可展开查看原始 JSON；非标准响应可能只显示原始响应提示。
- AI 结果不会写入主草稿、六类业务台账、周报或确定性规则。
- 请求超时为 60 秒，不自动跟随重定向，响应正文上限为 2 MB。
- 浏览器直连、本机中转和内网请求在停止等待或配置变化时会主动中止；Electron IPC 当前不能跨进程中止已经发出的调用，因此界面停止等待后会拒绝迟到结果。
- 结果是否包含可读正文取决于服务商是否真正兼容 OpenAI 响应格式。
- 当前有本机生成/回答历史，但没有多轮对话上下文、流式输出、自动重试、费用统计或自动写回。

### 21.5 润色指引（Skill）

“AI 助手”底部提供“公文写作指引库”，可以把写作方法论保存为可复用的润色指引：

- 新建：填写指引名称和内容后点击“保存指引”；也可以点击“导入 .md / .txt”批量导入本机 Markdown 或文本文件（单个文件不超过 500 KB，内容不超过 20,000 字符），例如《公文写作算法》蒸馏笔记。
- 使用：选择器默认是“无（默认）”，不会暗中附加任何写作指引；也可选择三份只读预制“精简润色版”“结构校核版”“总结成稿版”，或选择带“本机 ·”前缀的用户指引。更换指引会撤销当前确认状态，需要重新勾选确认。
- 边界：指引保存在本机设置库并进入快照备份，不参与内网同步，也不会写入业务记录；公开直连、互联网桌面 IPC 和私有网关三个边界统一限制单条指引不超过 20,000 字符。指引只影响 AI 的表达方式，材料仍需脱敏并逐次确认，AI 输出仍为只读。
- 删除：只读预制不能删除；本机指引可在指引库列表点击删除并确认，已删除选择会自动回退为“无（默认）”。

### 21.6 本机 AI 历史与字段变化

- 每次得到标准文本回答后，系统把用途、服务商、模型、指引名称、已确认脱敏的请求、回答和字段变化保存为本机历史；不保存 API Key、访问码、会话令牌或未脱敏原文。
- “AI 助手”中的“历史生成与回答查询”可搜索用途、模型、指引、请求、回答和字段名称；选择左侧记录后在右侧查看详情。
- 公文写作和周报入口会比较调用时的标题/正文快照与 AI 返回内容；普通材料请求以“生成结果”展示前后摘要。字段变化只是说明，不代表系统已经修改业务记录。
- 最多保留 200 条；回答超过 200,000 字符时历史只保留前段并明确提示。可删除单条或确认后清空全部。
- AI 历史保存在当前客户端 IndexedDB，进入本机快照，但不进入私有同步。删除历史后无法撤销，操作前可先导出快照。

### 21.7 本机中转站与神秘站点

当兼容 API 在浏览器中提示 `Failed to fetch`，通常表示浏览器没有拿到可交给页面的响应。常见原因包括服务商未允许当前 Pages Origin、Chrome 的 Local Network Access 权限被拒绝、证书或 DNS 错误、地址不可达，或者终端安全软件拦截。该错误发生在浏览器与服务之间，不能靠更换模型 ID 修复。

自 v0.6.5 起提供可选的本机中转方式：

1. 在当前设备运行根目录的 `start-local-relay.cmd`，或在 `hxhwang-gw-server` 中运行 `pnpm dev`。
2. 打开 `http://127.0.0.1:8787/relay-admin`，输入本机管理密码。
3. 后端预留“神秘站点 01/02/03”三个槽位。填写显示名称、OpenAI 兼容上游基址、API Key、鉴权方式、API 路径、默认模型和启用状态，然后点击“保存并发布站点数据”。鉴权默认选择“自动”：先发送 Bearer，只有上游返回 `401` 或 `403` 才改用 `x-api-key`；已知服务商要求固定方式时可直接选择对应项。API 路径默认选择“自动兼容”：先在基址后使用 `/v1/models`，若上游返回 404/405、无效 JSON 或空列表，再尝试直接追加 `/models`。已知站点要求标准 OpenAI 路径时选“自动补 `/v1`”，要求 `https://host/api/models` 一类路径时选“直接追加资源”。留空 API Key 会保留原值，勾选“清除 Key”才会删除。
4. 保存后在对应站点卡片点击“测试已保存配置”。未启用站点也可测试，但不会出现在 Pages 目录。诊断只请求模型列表，不发送聊天材料；结果显示总耗时、模型数量/预览，以及每次尝试的路径、鉴权、HTTP 状态和稳定错误分类。测试不会写配置或改变 revision；若表单有未保存修改，测试仍使用上次保存版本。
5. 回到 AI 助手，在“服务商预设”选择“神秘站点（本机中转 · 需密码）”。填写密码不会联网；点击“解锁并刷新站点”后才联系 `127.0.0.1`。
6. 选择带“神秘 ·”前缀的站点，点击“获取中转站模型”。后台按该站点的 API 路径模式访问上游模型端点，网页只得到保持上游顺序且去重后的模型 ID。目录超过 8 项时可使用同一套本地筛选；再次点击“刷新中转站模型”时旧目录保持可用，可停止等待，失败不会清空当前选择；切换站点仍会使旧请求失效。
7. 生成脱敏预览、人工确认并发送。网页只提交 provider ID、模型、用途、指引和已确认脱敏内容；真实上游地址与 API Key 不会下发。
8. 后端配置有变化时点击“刷新站点”，界面会读取新的 revision 和已启用站点；不需要重新部署 GitHub Pages。

安全边界：

- 中转密码和 relay session 只存在当前 React 会话内存，刷新页面后需要重新输入。
- 用户指定密码只保存在被 Git 忽略的服务端 `.env`，不会进入 Pages、安装包、快照或 AI 历史。
- 上游配置使用独立随机 256 位密钥和 AES-256-GCM 写入 `hxhwang-gw-server/data/relay-providers.enc`；六位管理密码不是文件加密密钥。
- 本机服务强制监听回环地址；当前六位密码不是公网认证，不得把 8787 端口转发到局域网或互联网。
- 页面加载、选择入口、填写密码都不会自动请求本机中转；只有解锁、刷新、获取模型和确认生成会联网。
- 管理诊断必须由管理员点击触发，只返回脱敏尝试链；真实地址、API Key、底层异常和原始上游响应不会进入 Pages。诊断只验证模型列表连接，不等于聊天生成或生产健康保证。
- Chrome 142 及更高版本会在 Pages 首次联系 `127.0.0.1` 时请求“本地网络访问”权限。必须选择“允许”；若曾拒绝，请在地址栏的网站设置中改为允许并刷新页面。v0.6.1 会把回环请求标为 `loopback` 并显示这条恢复路径，但不会绕过用户授权。
- 其他浏览器可能使用不同名称或尚未实现同一权限模型；仍失败时可使用互联网桌面版，它不受浏览器 CORS 同等限制。

## 22. 内网同步与内部 AI

### 22.1 建立内网会话

1. 进入“AI 助手”。
2. 填写“内部 API 地址”。生产环境应使用 HTTPS；本机调试可使用回环 HTTP。
3. 填写一次性访问码。
4. 点击“建立会话”。
5. 成功后状态显示“已连接”，访问码输入框清空。

访问码只用于创建会话，客户端随后在内存中保存短期会话令牌。刷新或退出应用后通常需要重新建立会话。当前共享访问码模式只适合演示或受控内网，不是完整的组织账号和权限系统。

### 22.2 同步业务数据

1. 同步前导出本地快照。
2. 建立会话。
3. 点击“同步全部业务数据”。
4. 查看提示中的拉取、推送、冲突和附件上传数量。
5. 返回各模块抽查数据。

当前同步范围：

- 任务；
- 会议；
- 文件；
- 外出活动；
- 用章；
- 物资；
- 主草稿；
- 新周报；
- 六类业务的 active 记录、回收站完整记录和永久删除最小墓碑；
- 按 `updatedAt` 选出的有效业务 master 实际引用、且本机有正文和 SHA-256 的附件，以及有效远端记录引用而本机缺少的附件。

当前不在同步范围：历史档案、AI 历史、历史 Skill、常用人员和单位、自定义格式、润色指引、星标记录及其他本机设置。星标是当前设备偏好；需要迁移时应使用本地快照，不能把它误认为跨设备同步状态。

同一 ID 发生变化时，客户端按 `updatedAt` 比较；远端时间不早于本机时拉取远端，本机更新较新时尝试推送。较新的永久删除墓碑会覆盖较旧业务 payload，防止记录复活；收到远端墓碑后，本机只清理已无其他引用的旧附件。服务端返回冲突主版本时，客户端会用服务端版本写回本机，当前没有逐字段冲突合并界面。因此多设备编辑前后都应先同步并导出快照。

注意：未保存编辑器中的暂存附件不会进入快照或同步。同步先按 `updatedAt` 选出有效 master，再上传这些有效记录实际引用的附件；被较新墓碑替代的旧 payload 不会继续触发附件上传。不会因为附件仍存在于本机库就自动上传孤立附件；历史档案附件也不属于同步范围。

### 22.3 获取内部模型并发送

1. 建立内网会话。
2. 点击“获取内部模型”。请求期间按钮显示忙碌状态；内部地址或会话变化后，旧请求即使迟到也不会覆盖当前会话。
3. 已有目录时可点击“刷新内部模型”。刷新中继续使用当前目录，可停止等待；失败或取消保留上次目录，成功后尽量保留仍存在的当前模型。
4. 选择模型。目录超过 8 项时可使用本地关键词筛选；无匹配时保留当前模型，清除筛选后恢复完整顺序。
5. 选择处理用途、润色指引（可选）和本机素材，点击“载入素材”或粘贴自定义材料。
6. 点击“生成脱敏预览”。
7. 人工修改预览并重新核对材料范围。
8. 勾选“我确认本次材料已脱敏且允许发送到内部模型”。
9. 点击“确认发送到内部 AI”。发送中按钮显示“正在生成结果”并阻止重复提交；可点击“停止等待生成结果”。
10. 停止等待、修改用途/模型/材料/指引、重新建立会话或离开页面都会使当前生成失效。迟到响应不会更新结果或新增 AI 历史，上一条成功结果在新请求成功前保持可见。
11. 核对可读结果和原始响应；无论成功、失败或取消，再次发送前都要重新勾选逐次确认。

模型提供方 Key 只存放在私有服务端，客户端不能读取。内部 AI 结果同样只读显示，不会自动覆盖原稿。

## 23. 典型业务流程

### 23.1 从来文到周报

1. 先在“任务管理”新建需要承办的任务并保存。
2. 在“文件收发”登记来文，填写标题、文号、来源单位、承办人和附件。
3. 在同一文件抽屉的“关联任务”中筛选并勾选已保存任务，然后点击“保存文件”。
4. 在文件详情点击关联任务，或在任务详情点击反向关联文件，核对双向只读链路。
5. 添加配合单位和阶段，办理过程中持续更新状态和工作小结。
6. 周末进入“周报生成”，选择日期范围并重新汇总。
7. 人工补充经核实的事实，保存并导出。
8. 导出本地快照。

关系只由文件记录保存任务 ID，任务侧不保存第二份反向数组。关联筛选、详情解析和跳转只消费当前已加载 active 数组，不联网、不读第二份数据库，也不会把任务正文复制进文件。

### 23.2 从旧系统迁移后继续办理

1. 先在旧系统保留原始导出 JSON。
2. 在 HxHwang Gw 中导入并阅读迁移报告。
3. 抽查直接映射的新任务、新文件和只读历史档案。
4. 对需要继续办理的历史会议、外出、用章或物资事项，点击原件的“复制为新记录”。
5. 在对应编辑抽屉补齐必填字段和无效日期，保存新记录；需要总体跟踪时再建立任务，并在任务来源或备注中写明历史档案标题。
6. 返回历史档案确认原件及原始字段未改变。
7. 导出迁移完成后的快照。

### 23.3 从模板到正式公文

1. 在“公文写作”选择合适模板。
2. 填写标题、事实、依据、措施、责任和时限。
3. 参考“落笔检查”，逐项核对来源和严重程度。
4. 保存版本。
5. 如需 AI，只把经过人工脱敏并允许发送的片段复制到对应 AI 区域。
6. 人工选择返回内容，粘贴回主草稿并再次核对。
7. 导出 DOCX/PDF，在目标软件中检查字体和分页。
8. 正式发文前执行单位审签流程。

### 23.4 更换设备或浏览器

1. 在原设备导出快照。
2. 把快照通过受控介质转移到新设备。
3. 在新设备的公开 Pages、互联网版或内网版进入“数据迁移”，选择该 JSON。
4. 查看报告并抽查六类业务台账、草稿、周报、自定义格式、历史档案和附件。
5. 确认无误后再停止使用旧设备数据。

公开 Pages 可以恢复快照，但数据只写入新设备的当前浏览器；它不会自动出现在其他浏览器或通过 GitHub 账号同步。涉及内部材料时应优先使用受控桌面端或内网环境。

### 23.5 从会议、外出到成果归档

1. 在“会议管理”登记会议主题、对象、时间、地点和通知附件。
2. 如会议产生外出活动，在“外出活动”登记参与人员、活动内容和成果。
3. 如后续需要用章，在“用章管理”登记已经完成审批的文件和佐证附件。
4. 如发生物资领用，在“物资收发”按统一名称和规格登记领用流水。
5. 在“任务管理”更新相关任务的小结和阶段，不要用 AI 推断未录入成果。
6. 在周报中重新汇总六类素材，人工核对后保存和导出。

## 24. 常见问题与排查

### 24.1 日期无法保存或年份无法输入

- 确认使用真实 `YYYY-MM-DD` 日期，年份为四位且不早于 1900 年。
- 任务交办日期、文件成文日期和周报起止日期不能为空；任务截止日期及四个新增台账的业务日期可以为空。
- 可以先清空日期或年份再输入新的四位年份；控件在编辑过程中保留中间状态，只有完整有效值才写回记录。
- 无效值在失焦后会恢复为最近一个有效值；保存边界也会再次拒绝不存在日期或扩展年份。不要通过修改快照 JSON 绕过校验。
- 仍无法操作时记录浏览器/系统版本和最小复现步骤，不要在没有有效保存提示时认为修改已经完成。

### 24.2 常用人员或单位看起来被新值覆盖

- 原生候选列表会按当前输入过滤；使用字段下方“从全部常用项选择”查看完整人员或单位集合。
- 快速连续点击加号会串行合并，不应覆盖已有值；看到“已加入常用项”后可从完整选择器核对。
- 需要重命名或删除候选项时，进入“常用项管理”修改并点击“保存全部修改”；历史业务记录中的旧文字不会随候选项变化。
- 保存任一使用人员或单位的业务记录后重新打开，检查候选项是否存在。
- 常用项会进入本地快照。真正缺失时使用删除或异常发生前的快照核对，不要连续重复导入多个快照。

### 24.3 获取不到模型

- 公开 Pages 与互联网版都可使用用户自备 Key 的兼容 AI；内网版使用内部网关。
- 内网版先建立会话，再点击“获取内部模型”。
- 公开 Pages/互联网版检查服务商预设、地址、API Key 和 OpenAI 兼容接口。
- 浏览器版本还要检查服务商 CORS；互联网桌面版不依赖浏览器 CORS。
- `401/403` 通常表示访问码或 API Key 无效；`404` 通常表示路径错误；`429` 通常表示限流或额度问题；`502` 表示网关无法正常访问上游。
- 地址以 `/v1` 结尾即可，不要手工再添加 `/models` 或 `/chat/completions`。

### 24.4 AI 返回内容或原始 JSON

标准响应会显示可读正文，并在“查看原始响应”中保留完整 JSON；不兼容的响应可能没有可读正文。系统不会自动把结果写入文稿。人工核验后只复制需要采用的文字，不要把包含元数据、usage 或调试字段的整段 JSON 粘贴到正式公文。

### 24.5 数据在另一台电脑看不到

公开演示版和互联网版默认不会跨设备同步。使用“导出快照”转移；内网版也必须在两端建立会话并主动同步。浏览器书签同步、GitHub 登录或安装同一客户端都不会自动迁移 IndexedDB。

### 24.6 导入 DOCX 后版式变化

DOCX 导入目标是提取可编辑结构，不是像素级复刻 Word。页眉页脚、复杂表格、文本框、批注、分页和精确字体需重新检查。最终以导出的 Word/PDF 在目标设备上的预览为准。

### 24.7 PDF 没有直接下载

- Web 端会打开系统打印界面，请选择“另存为 PDF”。
- 如果浏览器阻止打印窗口，允许当前站点打印后重试。
- 桌面端应出现保存对话框；没有出现时先检查目标目录权限和剩余空间。
- 无论哪种方式，都要确认 A4、缩放、边距、页眉页脚选项和中文字体。

### 24.8 附件无法添加或下载

- 公开 Pages、互联网版和内网版都允许本机附件；公开 Pages 不会把附件上传到 GitHub。
- 单个文件超过 8,000,000 字节会跳过。
- 历史附件按钮禁用表示缺少本机正文或校验值。
- 浏览器阻止下载时，只为当前站点放行下载，不要关闭系统整体安全防护。
- 选择附件后还要保存当前任务、会议、文件、外出、用章或物资记录；取消编辑时暂存附件会被丢弃，不会进入快照或同步。

### 24.9 导入 JSON 失败

- 确认选择的是旧系统导出的 JSON 或 `hxhwang-gw-local-v1` 快照，不是 HTML 原型本身。
- 不要手工删除 `_meta`、记录 ID、附件 Data URL 或快照 `format`。
- 先保存原件，再复制一份用于排错。
- 查看提示是否为记录数超过 50,000、未知类型、无效载荷或跨类型 ID 冲突。

### 24.10 误删记录

若只是普通删除，进入“回收站”找到记录并点击“恢复”。若已经永久删除，只能寻找永久删除前导出的快照，在隔离的测试浏览器配置中恢复、核对并重新保存该记录以刷新更新时间，再决定是否同步；永久删除后才导出的快照只含墓碑，不能恢复业务正文。正式恢复前仍应导出当前状态。

### 24.11 页面仍显示旧版本

1. 核对地址必须是 `https://nextweb4.github.io/gw/`。
2. 关闭该站点的其他标签页并重新打开。
3. 等待 Service Worker 更新后刷新。
4. 若需清除站点数据，必须先导出快照；清除缓存时可能同时删除 IndexedDB 业务记录。

### 24.12 删除全部记录后样例是否会重新出现

当前版本通过 `demo-seed-v3` 标记只执行一次省级样例初始化。未修改的旧样例会升级为新样例，用户已经编辑过的同 ID 记录保持不变；标记存在时，删除全部任务或其他台账后不会反复重建样例。只有整个本地数据库连同该标记一起被清除后，下一次启动才会重新初始化样例。清除浏览器站点数据前必须先导出快照。

### 24.13 历史记录为什么不能直接编辑

迁移原件必须保持只读，避免后续编辑破坏来源证据。会议、外出、用章和物资原件可点击“复制为新记录”，在对应独立模块中补齐并保存；旧周报和未知类型只能查看。任务和文件若已被迁移器映射，则直接进入可编辑业务列表，未映射字段仍以只读 JSON 保留。

### 24.14 物资库存出现负数或分成多个项目

- 负数表示现有领用流水合计大于入库流水，系统不会自动阻止。核对漏登入库、错误数量或误删记录。
- 名称和规格必须一致；大小写、全半角、内部空格或规格差异会形成不同库存键。
- 搜索不会改变库存计算范围。修正相应流水并保存后，账面库存会自动重算。

### 24.15 API Key 刷新后消失

这是密钥边界，不是保存故障。API Key 只保留在当前页面或桌面会话内存，刷新、关闭页面或退出应用后必须重新填写。不要把 Key 写进快照、备注、文稿或自定义格式。

## 25. 日常操作检查清单

### 25.1 每日录入前

- 核对运行模式和版本。
- 确认当前浏览器/系统用户正确。
- 抽查前次六类业务台账、主草稿和已保存周报是否存在。
- 内网多设备使用时，先导出快照再同步。

### 25.2 保存记录后

- 等待保存成功提示。
- 回到列表核对名称、日期和状态。
- 重新打开抽查本模块的关键字段、原始字段和附件关联；物资还要核对账面库存。
- 不把页面仍显示编辑内容当作已经持久化的证据。

### 25.3 使用 AI 前

- 确认材料允许发送到目标模型服务。
- 删除涉密信息、个人敏感信息和无关附件内容。
- 检查本地脱敏预览，不依赖自动规则兜底。
- 确认服务地址、模型和用途。
- 只在本次确认后发送，返回内容逐句核验。

### 25.4 导入、升级或批量删除前

- 导出当前快照。
- 核对快照格式和记录数组。
- 保留原始导出文件，不在原件上修补。
- 在测试配置中验证恢复。
- 记录迁移报告中的数量和警告。

### 25.5 正式导出前

- 核对标题、文号、时间、单位、姓名、数据和政策依据。
- 检查确定性规范提示。
- 在目标 Word/PDF 阅读器中检查 A4、字体、边距、分页和空白页。
- 经过单位规定的审签、保密和发布流程。

## 26. 当前版本未提供的功能

为避免把规划当成现状，`v0.7.21` 明确未提供：

- 组织账号、角色权限、审批流、电子签章和完整审计日志；
- 周报、草稿、AI 历史、常用项和历史档案的统一回收站；
- 回收站自动 30 天清理、跨记录批量选择恢复或按保留策略自动销毁；
- 独立附件库浏览、导入遗留孤立附件扫描和手工批量清理；
- 事务日历提醒、邮件/短信通知、外部日历订阅、重复事项、周/日时间轴、拖拽改期、车辆调度、印章设备控制、物资采购审批和库存盘点调整单；
- Excel 批量导入、扫描件 OCR、复杂 Word 无损导入；
- 后台自动同步、自动冲突合并和离线同步队列；
- AI 多轮对话上下文、云端历史同步、流式输出、自动写回、费用统计和准确性保证；
- 应用层本地数据库加密、代码签名和正式涉密处理能力。

这些能力只有在代码、测试、帮助文档和发布资产全部完成并验证后，才能在说明书中标记为可用。
