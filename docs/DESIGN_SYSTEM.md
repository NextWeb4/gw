# HxHwang Gw 视觉系统

版本：v0.2.1。视觉方向为“动态档案 / 墨迹信号”：将公文纸张的秩序、档案索引的编号感和本地数据流的实时信号组合成一套暗色、高对比、编辑式界面。该系统不复制任何参考站的页面、素材、提示词或代码。

## 视觉原则

- 主画布使用近黑色与低透明网格，强调资料在本机聚合的空间感；荧光黄只用于主操作、活动状态和确定性信号，朱红用于风险或超期，紫色仅作为环境光。
- 标题使用本机中文宋体/中宋回退栈并采用大字号、紧行距和轮廓字；正文使用本机黑体回退栈。运行时禁止加载远程字体或公共 CDN。
- 内容面板使用低透明暗面和细边界；正式文稿编辑区保持暖白纸张，保证长篇中文阅读和打印心智一致。
- 界面中的功能图标全部来自 `lucide-react`。不得使用表情符号、图标字体、Unicode 图形字符或额外自绘功能 SVG。

## 动效与渲染

- `KineticBackdrop` 根据指针位置更新 `--pointer-x`、`--pointer-y`，只驱动本地 CSS 光场；该层不进入无障碍树、不接收点击、不读取业务数据。
- 首屏使用分层环形轨道、扫描扇面和分批文字入场建立空间深度；表格、卡片和按钮只使用短距离、可逆的位移与颜色反馈。
- `prefers-reduced-motion: reduce` 下关闭持续动画、长过渡和指针光场，功能及信息层级不得依赖动画才能理解。
- 动效不得引入 WebGL、第三方运行时或外部网络资源；Pages、桌面端和内网 Web 复用同一套本地 CSS 与 React 结构。

## 响应式与无障碍

- 桌面基线为 1440×900：左侧索引导航、粘性状态栏、宽幅工作画布。
- 移动基线为 390×844：导航转换为底部八入口图标栏，正文在导航上方的独立容器内纵向滚动；正文可视区域底边不得越过导航顶边。宽表格仅在自身容器内横向滚动，不允许页面级横向溢出。
- 所有仅图标按钮必须提供 `aria-label` 或 `title`；键盘焦点使用荧光黄双像素轮廓；装饰层必须 `aria-hidden`。
- 长中文标题、空状态、错误状态、抽屉、编辑器和打印模式均需单独检查，不得以视觉效果牺牲可读性。

## 验证要求

- 每次视觉改动至少运行 `pnpm lint`、`pnpm test:e2e` 与 `pnpm build`。
- 在 1440×900 和 390×844 检查工作台、任务列表、公文写作和抽屉；确认页面无横向溢出、控制台无错误、Pages 无第三方请求。
- 使用源码扫描确认 `apps/web` 没有表情符号、远程字体、公共 CDN或非 Lucide 功能图标。
