# 《公文写作算法（最新版）》蒸馏笔记

> 顿彬 著 | 郑州大学出版社 | 2021年12月 | 294千字
>
> 核心理念：**公文写作 = 行政信息数据处理**——将公文写作视为一种"算法化"过程，通过基因、成分、剧情、框架四层体系，系统解构公文的底层逻辑与写作技法。

---

## 一、全书核心框架

### 1.1 总体写作方法论

本书提出将公文写作类比为编程算法，书名"公文写作算法"的内核在于：**公文写作是可拆解、可复用、可训练的算法体系**。全书从"基因→成分→剧情→框架"四个层面逐层递进，最终达到"高观点"层面的写作境界。

### 1.2 六大知识层次（全书结构）

| 层次 | 名称 | 定位 | 核心内容 |
|------|------|------|----------|
| 第一层 | 基因层面 | 微观基础 | V+N / N+V 语法基因、技能矩阵 |
| 第二层 | 微观部分 | 句子层面 | 3V+N 句式、"四大金刚"、首段结构 |
| 第三层 | 中观部分 | 段落/工作层面 | 工作周期、"工作剧情" |
| 第四层 | 中观部分 | 成分分析 | "公文成分"概念、水分与干货理论、六大逻辑 |
| 第五层 | 宏观部分 | 全文框架 | 18 种文体完整框架与写作流程、标题分形学 |
| 第六层 | 高观点层面 | 策略与心法 | 地空对接、概念封装、产品化、大局观 |

### 1.3 四个层次的能力模型——"技能矩阵"

作者提出公文写作能力的四层次模型：

```
| 层次 | 能力 | 标准 | 通关标识 |
|------|------|------|----------|
| 第一层 | 会写 | 能独立完成各类公文材料 | "小白"突破线 |
| 第二层 | 会改 | 能精准诊断并修改他人文章 | 准专业 |
| 第三层 | 会拆 | 能拆解任何优秀文章的结构与技法 | 专业 |
| 第四层 | 会创 | 能创造新的写作框架和表达方式 | 专家 |
```

## 二、写作算法/流程

### 2.1 写作的正确工作流程（四步法）

> 公文写作像玩雕塑：先从宏观整体雕出大致形状，再不断精雕细琢。想毕其功于一役是不可能的。

| 步骤 | 动作 | 关键要点 |
|------|------|----------|
| 第一步 | 详细请示领导 | 搞清楚汇报什么、突出什么重点、领导自己的想法 |
| 第二步 | 拟定框架+提交 | **在写内容之前**先把框架给领导审阅，及早发现问题 |
| 第三步 | 框架通过后深化细化 | 不断补充句子段落，在相对确定后再呈领导 |
| 第四步 | 反复修改 | 主动多次找领导修改，完成的标志是"领导不再提意见" |

**经典错误流程（作死流程）**：接到任务→闭门造车→截止时间发领导→四个字"立刻重写"。原因是：公文写的是单位的事，一个人很难把握全部信息；应该主动沟通、提前汇报框架。

### 2.2 各类文体的标准写作流程速查

| 文体 | 写作流程要点 |
|------|-------------|
| **工作简报** | 沟通任务→判断投放平台→确定篇幅→找准小点+剧情分解→隔山打牛（参考新闻稿中的措施部分） |
| **工作计划** | 读上级精神（奉天子以令诸侯）→思维导图提取名词体系→地空对接设计落实性工作→随时沟通汇报 |
| **工作总结** | 梳理上级+本级计划方案→梳理日常通知方案（重要工作才有通知）→从新闻/通讯/简报中捞素材→用 V+N/N+V 整合统一→冷处理修改（休息 1-2 小时后回看纸质版） |
| **工作报告** | 与工作总结流程一致，但需要更多团队沟通；语言更精炼、结构更规范 |
| **心得体会** | 阅读活动安排（掌握背景/目的/意义）→蹭时事热度→抓一个小突破口（内卷化：少即是多）→回到本职工作（移情：联系实际工作） |
| **领导讲话** | 参考工作总结流程，需额外积累：紧跟时事、了解领导想法（写人心最难） |
| **工作通知** | 读上级通知找关键要求→找单位过去正式文件研究规范→必要时参考市级/省级/国务院官网→细化名词体系 |
| **工作方案** | 读上级计划方案→内部沟通（会议研讨/请示汇报）→借鉴上级框架+完善本级工作（最难：将上级思想转化为本级手段和产品） |
| **述职报告** | 认真阅读组织部通知（框架暗含在通知里）→找单位素材（按领导分工分配成绩）→框架请领导过目再细化 |
| **调研报告** | 确定选题+二次缩小→判断写问题还是写经验→从单位找相关素材→添加精准数据→随时向领导汇报 |
| **新闻稿** | 判断类型（会议/活动/调研）→找四要素（时间/地点/人物/事件）→做填空题→从领导讲话/工作总结中找内容补充 |
| **通讯稿** | 复习框架→找工作简报做底本→干货改水分（加入对白/举例/故事）→每分点制造冲突（按照"背景→问题→解决→结果"） |
| **先进事迹** | 阅读上级通知掌握表彰方向→充分与表彰对象沟通（获取数字化成绩）→干货式表达 |
| **对照检查材料** | 仔细阅读上级通知（确定剖析问题）→参考周边单位把握力度→参考上级召开民主生活会的新闻通稿 |
| **党课** | 参考事前类领导讲话框架→侧重党的理论；最核心：成分+剧情是否完全驾驭 |
| **微型党课** | 全文充满故事：开头/转折/案例/结尾都可以是故事（难度最高，需要大量刻意训练） |
| **会议纪要** | 只保留一把手最后决定的内容和意见→其他发言全部删掉；格式参照本单位过去纪要 |

### 2.3 通用写作检查点（每篇文章必查）

1. **首段**是否包含完整的"按→拿→推"结构？
2. **主体分点**是否按成分正确构建（措施+成绩/计划+目标/水分+干货）？
3. **句式**是否以 V+N 为主？是否符合"V+N 纯粹性原则"？
4. **标题**是否正确使用独角兽型/双子座型？
5. **结尾**是否包含号召（如适用）？
6. **上级精神链接**是否放在段落/句子开头？
7. **概念封装**是否使用"虚部+实部"双名词结构？

## 三、结构模板库

### 3.1 工作简报的基本框架

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 时间状语 + 按 + 拿 + 推 |
| **主体部分**（3~5 个分点） | 每个分点：措施 + 成绩（重点讲成绩和产品化名词） |

**特征**：全部由"措施" + "成绩"组成（干货型）、不含水分成分。

---

### 3.2 工作计划的基本框架

| 组件 | 内容 |
|------|------|
| **标题** | ××年工作计划 / 要点 |
| **首段** | 工作思路：按 + 拿 + 推 |
| **主体部分**（3 个分点以上） | 每个分点：计划 + 目标（重点讲产品化名词） |

**语言特征**：几乎全部 V+N 结构、剧情只占少量、数字为大概而非精准、篇幅比工作总结短。

---

### 3.3 工作总结的基本框架

| 组件 | 内容 |
|------|------|
| **标题** | ××年工作总结 |
| **首段** | 时间状语 + 按 + 拿 + 推 |
| **一、工作完成情况**（必备） | 措施 + 成绩（重点讲成绩、剧情、产品化名词） |
| **二、存在的问题** | 问题成分 |
| **三、下一步打算** | 计划 + 目标（重点讲产品化名词） |

> 注意：存在问题、下一步打算两个部分看情况决定是否写（问上级领导，看过去的写作习惯）。

---

### 3.4 工作报告（政府工作报告级）的基本框架

| 大板块 | 子模块 | 成分 |
|--------|--------|------|
| **标题** | ××年工作报告 | — |
| **首段** | 约定俗成，直接借用上一年 | — |
| **一、××年工作情况** | 1. 整体工作完成情况 | 背景 + 按 + 拿 + 推 |
| — | 2. 主要成绩 | 最拿得出手的工作名词 + 数字 |
| — | 3. 主要做法 | 工作措施 + 成绩（突出动词） |
| — | 4. 表示感谢 | 感谢成分 |
| — | 5. 存在问题 | 问题成分 |
| **二、下一年工作计划** | 1. 形势分析 | 机遇与挑战 |
| — | 2. 明年工作目标 | 工作指标 / 重大型工作 |
| — | 3. 明年工作思路 | 按 + 拿 + 推 |
| — | 4. 主要工作安排 | 工作计划 |
| **结尾** | 号召 | 同志们 + 引用 + 工作要求 + 三组四字句 + 近目标 + 远目标 |

---

### 3.5 心得体会的基本框架

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 背景（大背景 + 小背景）+ 感触 + 引出后文 |
| **主体部分** | 每个一级标题下分为 2-3 个分点，每个分点 = **水分**（意义/背景/形势/引用/问题/举例/故事/正反论证/假设/成绩）+ **干货**（工作措施） |
| **结尾** | 号召 |

> 关键逻辑：经历一场"活动或工作"→ 引起内心新的认识 → 促进自己好好干工作（从虚到实、从知到行）。最后的落脚点永远是谈接下来如何做。

### 3.6 领导讲话的基本框架（四种分类）

#### A. 事前类领导讲话（工作部署会议、动员大会）

| 板块 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 会议大背景 + 小背景 + 要求 + 引出后文 |
| **一、思想意义层面**（侧重"因"） | 每个分点：水分（意义/背景/形势/引用等）+ 干货（工作要求） |
| **二、核心工作** | 每个分点：水分 + 干货（工作措施） |
| **三、对内要求** | 每个分点：水分 + 干货（工作措施） |
| **结尾** | 号召 |

#### B. 事中类领导讲话（推进会、调度会）

> 在事前类框架基础上，第一部分替换为：

| 一、成绩 + 问题层面 | 分点一：主要成绩；分点二：主要做法；分点三：主要问题 |

其余部分（核心工作、对内要求）与事前类一致。

#### C. 事后类领导讲话（总结表彰大会）

> 结构同事中类，三个大板块不变，但更侧重成绩复盘和经验总结。

#### D. 特殊类领导讲话（专题讲话、培训班讲话）

| 板块 | 内容 |
|------|------|
| **一、措施 1** | 每个分点：水分 + 干货（工作措施） |
| **二、措施 2** | 同上 |
| **三、措施 3** | 同上 |

> 即去掉"思想意义"和"对内要求"，全篇围绕具体措施展开。

| **结尾** | 号召 |

#### B. 新颖型

| 阶段 | 动作 |
|------|------|
| 开头 | 故事引出 → 直截了当直击主题 |
| 点题 | 拔高到核心 |
| 展开 | 回顾历史："历史三连" |

| 下降 | 回到自己 → 谈自身当前工作 |
| 结尾 | 号召 → 再次点题 |

#### C. 极限黄金型

| 阶段 | 动作 |
|------|------|
| 开头 | 故事引出（以书或故事开头） |
| 引申 | 故事拔高（使用红色故事） |
| 展开 | 分析三连（三个重要意义） |
| 收回 | 回到自己（使用主题对接自身） |
| 分解 | 分成三个要求（融合第一种微型党课） |
| 结尾 | 号召 → 回到自身 + 对接顶层 + 再次点题 |

#### B. 会议新闻型

| 会议强调 | 核心重点工作（最重要的部分，按分点撰写） |

### 3.13 新闻稿的基本框架（三种类型）

#### A. 会议新闻

| 组件 | 内容 |
|------|------|
| **标题** | 直截了当地表达某单位召开的某会议 |
| **首段** | 时间 + 地点 + 人物 + 事件（四要素。市级以上只出现一把手；县级以下可出现其他领导） |
| **会议详情** | 会议背景、议程、流程（部分可省略） |
| **领导讲话详情** | 会议指出 → 会议认为 → 会议明确 → 会议强调 → 会议要求 |

#### B. 活动新闻

## 四、语言与措辞规范

### 4.1 公文基因："V+N"和"N+V"

本书核心规律：**公文的"基因"只有两种基本结构**：

| 基因类型 | 结构 | 含义 | 典型示例 |
|----------|------|------|----------|
| **V+N** | 动词 + 名词（动宾结构） | 表达措施/行动 | "推进项目建设""强化制度建设""开展调研活动" |
| **N+V** | 名词 + 动词（主谓结构） | 表达成绩/结果 | "项目建设取得突破""营商环境持续优化""经济指标稳步增长" |

### 4.2 "V+N"纯粹性原则（三大铁律）

1. **不以主体词（主语）开头**。正确：推进项目建设。错误：我们推进项目建设。
2. **逗号之间不超过 25 个字符**。保持句子节奏紧凑。
3. **尽量不用"的"字**。"的"会弱化动词力量。

### 4.3 "四大金刚"句式（通用句型）

> 公文句子的标准展开顺序：

```
目标 → 过程 → 措施 → 结果
```

- **目标**：为了……/旨在……
- **过程**：通过……/坚持……
- **措施**：V+N（核心动词+名词）
- **结果**：N+V（产品化名词+数据/成效）

### 4.4 首段"按、拿、推"结构

| 元素 | 含义 | 说明 |
|------|------|------|
| **按** | 按照/依据什么精神/要求 | 交代工作来源和依据 |
| **拿** | 采取了什么行动/大手笔 | 有两种角度——"过程性拿"（做了什么过程）和"结果性拿"（直接呈现做了什么） |
| **推** | 推出了什么成绩/效果 | 有两种——"务虚推"（概括性成果）和"务实推"（具体数据/产品化名词） |

### 4.5 "3V+N"经典句式结构

在"四大金刚"基础上，句子中的动词（V）可以拆分为 3 个层次：

- V₁：方向性动词（如"坚持""贯彻""推进"）
- V₂：方法性动词（如"通过""以""利用"）
- V₃：操作性动词（如"开展""组织""实施"）
- N：核心名词（产品化名词）

### 4.6 高频固定搭配/套话速查

#### 按（依据类）
- 根据……精神/要求/部署
- 按照……安排
- 贯彻落实……要求
- 认真学习……精神
- 坚决执行……决策部署

#### 拿（行动类）
- 精心组织、周密部署
- 统筹推进、协调联动
- 攻坚克难、锐意进取
- 抢抓机遇、乘势而上
- 创新举措、打造平台

#### 推（成果类）
- 取得了显著成效
- 实现了历史性突破
- 迈上了新台阶
- 开创了新局面
- 呈现出良好态势

#### 号召结尾公式
```
同志们 + 引用（上级精神/名言） + 工作要求 + 三组四字句 + 近目标 + 远目标
```

### 4.7 禁用词和冗余表达

| 类别 | 说明 | 错误示例 |
|------|------|----------|
| **口语化表达** | 领导讲话可用少量口语；书面公文禁用 | "就……那个……" |
| **冗余修饰** | 尽量不用"的"；形容词精简 | "大力地推进了重大项目建设" → "推进重大项目建设" |
| **主体词前置** | 不以"我们""本单位"开头 | "我们积极开展工作" → "积极开展工作" |
| **过度主观** | 避免个人感情判断词 | "非常""特别""极其" |
| **模糊词汇** | 成绩部分必须有具体数据和产品化名词 | "取得了一定成绩" → 必须写具体数字 |

### 5.1 范例一：首段"按、拿、推"分析

**结构分析**：

| 层次 | 技法 | 分析 |
|------|------|------|
| 段落前 | **地空对接** | "围绕提升党组织服务的'硬实力'"——上级精神链接 |
| 段落前 | **概念封装** | "集体经济丰羽'行动"——中间层产品化 |
| 后续分点 | **措施+成绩** | 每个分点 = V+N（措施）+ N+V（成绩+数据） |
| 分点一 | 成绩数字化 | "1万亩""全省第二个万亩烟叶镇""8~10万元" |
| 分点二 | 产品化名词 | "龙头企业+专合组织+产业基地""省级标准化畜禽养殖示范小区" |
| 分点三 | 举例 | 双铺村/新和村具体案例（"英雄之旅"冲突模型） |
| 全段逻辑 | 从上到下 + 从虚到实 | 上级精神 → 产品化概念 → 具体措施 → 数据成绩 |

### 5.3 范例三："地空对接"与概念封装——中建集团火神山/雷神山

## 六、速查手册

### 一页纸公文写作速查清单（可作为系统提示词引用）

```
【公文写作算法速查卡】

■ 基因：V+N（措施/行动） + N+V（成绩/结果）

■ V+N 纯粹性：不以主语开头 | 逗号≤25字 | 不用"的"

■ 句式（四大金刚）：目标 → 过程 → 措施(V+N) → 结果(N+V)

■ 首段公式：时间状语 + 按（依据） + 拿（行动） + 推（成绩）

■ 成分两大类别：
  - 水分：意义/背景/形势/问题/引用/例子/故事/假设/正反论证/要求/感谢/号召
  - 干货：工作措施/工作计划/工作目标

■ 六大行文逻辑：
  从古到今 | 从上到下 | 从大到小 | 从虚到实 | 从外到内 | 从知到行

■ 标题结构：
  - 独角兽型：纯 V+N 或纯 N+V
  - 双子座型：V+N,N+V 组合
  - 核心原则：无限分形 + 自相似性 + 完整统一

■ 工作周期四阶段：启动 → 执行 → 保障 → 反馈

■ 文章类型判断：通过"措施"与"结果"在文章中的占比来判断是哪种文章

■ 写前必做：请示领导意图 → 拟框架 → 提交领导审阅 → 再细化内容

■ 三大拔高技巧：
```
